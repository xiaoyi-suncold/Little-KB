# 四轴（FJ5）vs 六轴（光伏清洗）参数差异分析

## 结论

1. 两表共 1056 / 1069 条参数，998 条同名；**223 条值不同**，其中 **102 条是校准与设备身份数据**（换机必然不同，无工程意义），真正的调参差异 **39 条控制、10 条安全、28 条硬件**。
2. 四条需要立刻确认的红旗：**两边都没开电子围栏**（FENCE_ENABLE=0）；**四轴低电量与严重低电量都不触发任何动作**；**六轴 ARMING_CHECK=334 跳过了 INS 等自检**；**六轴电压参数内部不自洽**（BATT_* 指向 16S，MOT_BAT_VOLT_MAX=75.6 指向 18S）。
3. 两表来自**不同固件版本**：四轴用 `GPS1_*`（14 条）与 `GPS_*`（13 条）混排，六轴用 `GPS_*`（37 条）；直接 diff 会产生 58 / 71 条假"独有参数"。
4. 六轴表里出现 `WATER_PUMP_*`、`SURFTRAK_*`、`BTN_*`、`GPS_CAN_NODEID*`，**不是标准 Copter 参数组**，说明是厂商定制固件或参数集被合并过——**不能把差异项直接照搬到标准固件**。

## 平台级差异

**电压平台**：四轴自洽于 12S（满电 50.4V / 解锁 44.3 / 低电 43.2 / 严重 42）。六轴的三条 BATT 阈值（66.5 / 64.8 / 63）对应 16S（4.2V×16=67.2），但 `MOT_BAT_VOLT_MAX=75.6`、`MOT_BAT_VOLT_MIN=59.4` 对应 18S。**同一张表里两套电芯数假设**，先量一次实际电芯数再动任何电压参数。

**容量与任务画像**：3300 mAh vs 47000 mAh；巡航 10 m/s vs 2 m/s；上升/下降 2.5/1.5 vs 0.5/0.3 m/s；加速度 2.5 vs 1.1 m/s²。六轴是"低速贴板清洗"，四轴是"转场快、作业粗"。

## 控制调参差异与解释

| 参数 | 四轴 | 六轴 | 解释 |
| --- | --- | --- | --- |
| `ANGLE_MAX` | 30° | 23° | 六轴作业更保守，抗风倾斜余量换稳定 |
| `ATC_ANG_RLL/PIT_P` | 4.5 | 3.2 | 四轴角度环更硬 |
| `ATC_RAT_RLL/PIT_P` | 0.135 | 0.1 | 同上，四轴响应更快 |
| `ATC_RAT_RLL/PIT_D` | 0.0036 | 0.0015 | 四轴 D 高 2.4 倍，抑制快速振荡 |
| `ATC_RAT_RLL_PIT_I` | 0.135 | 0.079~0.09 | 四轴积分更强 |
| `ATC_RAT_YAW_P / I / D` | 0.18 / **0.018** / 0 | 0.13 / **0.12** / 0.0016 | 关键分歧：四轴几乎不用偏航积分，靠 P 顶；六轴靠 I 消稳态误差并加 D 阻尼 |
| `ATC_ACCEL_R/P_MAX` | 15900 | 10000 | 四轴允许更猛的角度加速度 |
| `ATC_RATE_*_MAX` | 0（不限） | 60% | 六轴给角速度输出留了 40% 余量 |
| `PSC_VELZ_P / ACCZ_P / ACCZ_I` | 3.0 / 0.30 / 0.70 | 5.0 / 0.44 / 0.88 | 六轴垂直环明显更硬，配 50L 水箱的变载 |
| `MOT_THST_HOVER` | 0.16 | 0.20 | 都远低于默认 0.35，推重比偏大或标定偏差 |
| `MOT_THST_EXPO` | 0.65 | 0.89 | 六轴油门曲线更弯，悬停点附近更细腻 |

偏航那一行是最值得深挖的：`YAW_I=0.018` 意味着四轴基本放弃偏航积分，持续侧风或喷水反扭会留下稳态航向偏差；而 `YAW_P=0.18` 偏高又容易在长机臂上激起偏航振荡。这种"高 P + 近零 I"通常是**被振荡逼出来的折中**，不是首选整定。

## 安全配置（红旗）

| 参数 | 四轴 | 六轴 | 风险 |
| --- | --- | --- | --- |
| `FENCE_ENABLE` | **0** | **0** | 围栏参数设了但不生效；六轴的 30m/30m 等于没设 |
| `BATT_FS_LOW_ACT` | **0（不动作）** | 2（RTL） | 四轴低电量只报警不返航 |
| `BATT_FS_CRT_ACT` | **0** | **0** | 两边严重低电量都不动作 |
| `ARMING_CHECK` | 1（全检） | **334** | 334 = BARO+COMPASS+GPS+RC+BATTERY，跳过 INS、参数、板电压、日志、任务、围栏 |
| `FS_EKF_ACTION` | 1（Land） | 2（RTL） | EKF 失效时：就地降落 vs 依赖 GPS 返航，各有失效模式 |
| `RTL_SPEED` | 0（回落 WPNAV 10m/s） | 200（2m/s） | 四轴返航速度是六轴的 5 倍 |
| `LAND_SPEED` | 50 cm/s | 30 cm/s | — |

`ARMING_CHECK=334` 的位定义取自 ArduPilot 源码 `libraries/AP_Arming/AP_Arming.h` 的 `Check` 枚举（BARO=1<<1、COMPASS=1<<2、GPS=1<<3、INS=1<<4、PARAMETERS=1<<5、RC=1<<6、VOLTAGE=1<<7、BATTERY=1<<8 …）。注意新版固件把"跳过项"移到了 `ARMING_SKIPCHK`，`ARMING_CHECK=1` 才是"全检"的哨兵值；两表里都没有 `ARMING_SKIPCHK`，说明这份导出偏旧或未收录该参数。

## 数据质量问题

1. 四轴表 `BATT_CAPACITY=3300`，但说明列写"47Ah"——注释是从六轴表复制的。
2. 四轴表 `MOT_BAT_VOLT_MAX=50.4`（12S），说明列自己标注"日志电压 53–54V 提示 14S，需确认"。
3. 两表说明列大量出现"本机"，指代的是不同飞机，跨表引用会误读。
4. 六轴的 `SURFTRAK_*` 是 Sub/Rover 的水面跟踪参数组，出现在 Copter 参数表里，进一步说明参数集被合并过。
