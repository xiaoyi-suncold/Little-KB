# 参数入库验证报告

## 结论

两份参数表共 **2125 条参数**已按「一行一个参数」写入 SQLite `params` 表（四轴 1056 / 六轴 1069），逐字段与源文件比对 **零差异**，无重名、无空类别、两种读取模式结果一致。参数名与 ArduPilot 官方文档（Copter 4.8-dev）的锚点匹配率为 **87.2% / 86.9%**，未命中的部分可完整归因为「旧版本命名」与「厂商定制参数」，不是解析错误。

## 方法：三层校验

### 第一层 · 结构校验（`scripts/verify_params.py`）

| 检查项 | 四轴 | 六轴 |
| --- | --- | --- |
| C1 行数一致 | 1056 / 1056 PASS | 1069 / 1069 PASS |
| C2 源表无重名 | 0 重复 PASS | 0 重复 PASS |
| C3 逐字段一致（值/类别/说明/提示/默认值） | 0 差异 PASS | 0 差异 PASS |
| C4 数值可解析 | 0 异常 PASS | 0 异常 PASS |
| C5 命名格式合法 | 0 异常 PASS | 0 异常 PASS |
| C6 类别与说明覆盖率 | 缺失 0 PASS | 缺失 0 PASS |
| C7 两种读取模式一致（read_only ↔ 普通） | 0 行差异 PASS | 0 行差异 PASS |

C7 是专门为「流式读取可能错位」设计的：`extract.py` 索引用 `read_only=True`，导入用普通模式，两者逐行比对可以证明索引正文与结构化数据来自同一份事实。

### 第二层 · 官方参数锚点覆盖

抓取 `https://ardupilot.org/copter/docs/parameters.html`（Copter 4.8-dev，6.0 MB，6048 个 section 锚点），把每个参数名转成锚点前缀（`ATC_RAT_PIT_P` → `atc-rat-pit-p-…`）做存在性检查：

| 机型 | 参数数 | 命中官方锚点 | 未命中 |
| --- | --- | --- | --- |
| 四轴 | 1056 | 921（87.2%） | 135 |
| 六轴 | 1069 | 929（86.9%） | 140 |

未命中样本可以分成两类，**没有一条是解析问题**：

1. **旧版本命名（已改名）**：`ANGLE_MAX`（4.8 改为 `ATC_ANGLE_MAX`）、`ARMING_CHECK`（让位给 `ARMING_SKIPCHK`）、`GPS_*`（改为 `GPS1_*`）、`PSC_ACCZ_D`（改为 `PSC_ACCZ_D_FF` 等）。
2. **厂商定制参数**：`WATER_PUMP_AUTO`、`SURFTRAK_AUTO`、`BTN_*`、`GPS_CAN_NODEID*`、`GPS_DELAY_MS`。

### 第三层 · 采样语义核对

| 参数 | 官方文档口径 | 表内值 | 判断 |
| --- | --- | --- | --- |
| `MOT_THST_HOVER` | 范围 0.125–0.6875，默认 0.35 | 四轴 0.16 / 六轴 0.20 | 均在范围内，但贴近下限，值得复核 |
| `ATC_ANGLE_MAX` | 0.1–80°，默认 45° | 表内旧名 `ANGLE_MAX`：30° / 23° | 语义一致，仅名字不同 |
| `GPS1_TYPE` | 值表含 9=DroneCAN、14=MAVLink | 四轴 9 / 六轴 9 | 一致 |
| `ARMING_SKIPCHK` | 默认 0（不跳过任何检查） | 表内旧名 `ARMING_CHECK`：1 / 334 | 334 在旧掩码语义下跳过 INS 等检查 |

## 从验证里得到的三个事实

1. **两份表基于较老固件**：旧命名大量残留，且四轴表同时出现 `GPS1_*`（14 个）与 `GPS_*`（13 个），说明参数集被不同版本拼接或手工整理过。
2. **六轴表混入非 Copter 参数组**：`SURFTRAK_*` 是 Sub/Rover 的水面跟踪参数，`WATER_PUMP_*` 非标准组，几乎可以确定是厂商定制固件。
3. **官方 4.8 已重命名关键安全参数**：按新文档去找 `ARMING_CHECK`、`ANGLE_MAX` 会扑空；给用户写回复时必须同时给新旧两个名字。

## 复现方式

```bat
python scripts\param_import.py           :: 已并入 kb.py param-import
python scripts\verify_params.py          :: 结构校验（14 项）
python scripts\verify_params.py --official data\official_params.txt
python scripts\kb.py param MOT_THST_HOVER
python scripts\kb.py param-diff 四轴 六轴
```

## 局限

- 官方锚点法只能证明「名字在 4.8 文档里存在」，不能证明某一版固件的行为一致；
- 表内「默认值」列是作者整理的参考值，未逐条与官方默认值比对（工作量大，且旧版本默认值会变）；
- 参数说明（desc/hint）来自用户的表，属于作者经验，未做事实性核验。
