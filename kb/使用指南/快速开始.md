# 快速开始

这个知识库的一切都从 `kb/` 文件夹开始。

## 放文件

- 方式一：点界面右上角的 **上传**，支持多选、拖拽。
- 方式二：直接把文件复制进 `kb/`（可建子文件夹当分类），然后点 **重建索引**。

分类就是文件夹名：`kb/技术笔记/xxx.md` 属于「技术笔记」分类，直接放在 `kb/` 根目录的文件归入「未分类」。

## 支持的格式

| 类型 | 扩展名 | 索引方式 |
| --- | --- | --- |
| Markdown | `.md` `.markdown` `.mdx` | 全文 |
| 纯文本 | `.txt` `.log` `.csv` `.json` `.yaml` `.ini` | 全文 |
| Office | `.docx` | 段落 + 表格文本 |
| 网页 | `.html` `.htm` | 去标签后的正文 |
| 代码 | `.py` `.js` `.ts` `.go` `.java` `.sql` … | 全文 |
| 其它 | `.pdf` `.png` `.zip` … | 仅文件名与路径 |

## 检索语法

- 空格分隔多个关键词，多个词之间是「并且」关系。
- 中文按字建立索引：输入 `知识库` 会优先匹配连续出现的「知 识 库」；没有结果时自动放宽为包含这些字即可。
- 英文按单词前缀匹配，输入 `upload` 能命中 `uploader`、`uploading`。
- 文件名、路径、标签也参与检索，会额外加分。

## 维护

- **重建索引**：重新扫描 `kb/`，按内容哈希判断是否需要更新，不会重复建索引。
- 索引数据库：`data/kb.sqlite3`，删掉它再重建即可完全重来，不会动你的原始文件。
- 删除文档：在阅读区点「删除」，文件会从 `kb/` 中移除。
