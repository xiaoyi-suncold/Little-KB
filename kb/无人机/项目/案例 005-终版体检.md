## 2. 必须处理的隐患

### 2.1 电池平台错配（14S 实飞，参数按 12S）

日志电压 **51.88–58.97 V** → 14S（58.97/4.2 = 14.0）。

参数却是 12S：

| 参数 | 当前 | 14S 应为 |
| --- | --- | --- |
| `MOT_BAT_VOLT_MAX` | 50.4 | 58.8 |
| `MOT_BAT_VOLT_MIN` | 39.6 | 46.2 |
| `BATT_ARM_VOLT` | 44.3 | 51.8 |
| `BATT_LOW_VOLT` | 44.0 | 50.4 |
| `BATT_CRT_VOLT` | 42.0 | 48.3 |

后果：电压补偿全程被钳在 1（不补偿），推力随电量下降；低电量保护要到 44 V（3.14 V/cell）才触发，等于没有。

### 2.2 电流读数恒为 0

`BATT_MONITOR=8`（DroneCAN），但日志里 `BAT.Curr` 全程 0.008 A 量级。意味着：
- 电量百分比不可信；
- `BATT_CAPACITY`/容量保护不可用；
- `BATT_FS_LOW_ACT` 只能靠电压，不能靠容量。

需要确认 DroneCAN 电池是否输出电流，或该电池包本身没有电流计。

## 3. 应当处理

| 项目 | 现状 | 建议 |
| --- | --- | --- |
| 围栏 | `FENCE_ENABLE=0`（类型/半径/高度都配了但没开） | 开 |
| 高度源 | 气压−EKF 差 **−3.4 m**，全程漂 **3 m** | GPS 高度慢漂，参数只能软化 |
| 水平校准 | `AHRS_TRIM_X=2.63°`、`Y=1.26°` | 重做水平校准，压到 0.5° 内 |
| 振动 | X 35.5 m/s²，`INS_HNTCH_ENABLE=0` | 桨平衡 + 开 FFT 找桨叶频率 |
| 起转余量 | `MOT_SPIN_ARM = MOT_SPIN_MIN = 0.1` | 把 ARM 降到 0.08，留起转余量 |

## 4. 观察项

- GPS 为 3D fix（非 RTK 固定解），若依赖 GPS 航向（`COMPASS_ENABLE=0`、`EK3_SRC1_YAW=2`），需确认双天线基线状态；
- `BATT_CAPACITY=3300` 与 43.7 分钟航时矛盾，实际容量应在 30 Ah 量级；
- 43 分钟长航时后收尾 3.71 V/cell，属正常但已到常用下限。

## 6. 电池结论修正（按用户说明）

- **正式配置是 12S**（后面上系留箱，只用 12S）→ 参数保持 12S 那套（`MOT_BAT_VOLT_MAX=50.4`、`BATT_ARM_VOLT=44.3`、`LOW=44`、`CRT=42`）是**正确的**；
- 这次日志是**临时用 14S 电池测试**（58.97→51.88 V），所以看起来"错配"；
- 14S 测试期间要知道两件事：电压补偿被钳在 1、低电量保护（44 V）在 14S 上等于 3.14 V/cell 才会响，等于没有——测试时靠计时/地面站电压看着；
- `XILIU_FJ_终版1_14S与围栏修正` 只用于 14S 测试包，正式 12S 不要加载。
