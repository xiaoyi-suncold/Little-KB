# 案例 006：清洗无人机 25 MPa 工程复核

> 来源：`多旋翼清洗无人机工程计算_AI投喂包.zip`（Markdown 投喂包 + `清洗无人机倾角反推力与泵压安全计算表_25MPa修订版.xlsx`）。
> 方法：不改输入假设，按原始公式逐项复算，再按物理边界重新分层判定。

## 1. 表内计算复核（全部一致）

| 计算项 | 表内 | 复算 | 判定 |
| --- | --- | --- | --- |
| 整机重力 W = 49 × 9.80665 | 480.53 N | 480.53 N | 一致 |
| 推重比 105.6 / 49 | 2.155 | 2.155 | 一致 |
| 16° 水平力 W·tan16° | 137.79 N | 137.79 N | 一致 |
| 25° 水平力 W·tan25° | 224.07 N | 224.07 N | 一致 |
| 8° 实测对应水平力 | 67.53 N | 67.53 N | 一致 |
| 17 MPa：喷嘴 5.56 MPa → v=√(2P/ρ) | 105.45 m/s | 105.45 m/s | 一致 |
| 17 MPa：Q = Cd·A·v（Ø1.65 mm） | 13.53 L/min | 13.52 L/min | 一致 |
| 17 MPa：F = ρQv | 23.78 N | 23.77 N | 一致 |
| 管路损失（100 m × 6 mm，Darcy f≈0.021） | 隐含 11.4 MPa | 11.3–11.4 MPa | 一致 |
| 25 MPa：8.49 MPa / 16.71 L/min / 36.29 N | — | 一致 | 一致 |

结论：水力模型与反推力公式没有算错，不需要重推。

## 2. 三个安全边界

### 2.1 倾角：成立

| 约束 | 数值 |
| --- | --- |
| Loiter 参数上限 | 16°（`LOIT_ANG_MAX`） |
| 单轴连续负载反算 | 19.56° = acos(49/(4×13)) |
| 取小 | 16°，建议控制线 14° |

倾角由飞控参数而非动力决定，动力侧仍有 3.5° 余量。

### 2.2 推力：口径要分清

表里“46.9%”是相对**静态最大 105.6 kgf**；按厂家**连续推荐 13 kgf/轴（52 kgf）**：

| 工况 | 总拉力 | 单轴 | 占连续推荐 |
| --- | --- | --- | --- |
| 8° | 49.48 kgf | 12.37 kgf | 95% |
| 14° | 50.5 kgf | 12.63 kgf | 97% |
| 16° | 51.0 kgf | 12.75 kgf | 98% |
| 25° | 54.1 kgf | 13.5 kgf | **104%（超连续额定）** |

25° 不只是“角度大”，已经超出单轴连续推力额定，只能瞬时使用。

### 2.3 力矩：未闭环

`M = F_jet × h`。25 MPa 时 F_jet = 36.3 N：

- h = 0.1 m → 3.6 N·m
- h = 0.3 m → 10.9 N·m

按 8° 工况每轴剩余推力约 0.63 kgf、力臂约 0.9 m 估，飞控反力矩能力约 5–6 N·m 量级，**h 超过 0.15–0.2 m 就可能顶不住**。结论需要实测 h。

## 3. 25 MPa 可行性（分层）

| 层面 | 结论 |
| --- | --- |
| 水力 | 可达，但取决于喷嘴 K 值；16.71 L/min < 泵额定 20 L/min |
| 射流反力 | 36.3 N（3.7 kgf），占 16° 能力 26% |
| 倾角 | **9.5°–11.7°，低于 14° 控制线，安全** |
| 推力 | 单轴 12.4 kgf，仍低于 13 |
| 力矩 | 未验证（缺 h） |
| 振动 | 风险项：17 MPa 已 32–38.5 m/s²，25 MPa 流量 +23% 会更差 |

**关于 11.68°**：表内把 17 MPa 的**总扰动 67.5 N 整体线性放大**到 99.3 N，偏保守；只放大射流分量时：

```
25 MPa 水平力 = 67.5 + (36.3 − 23.8) = 80.0 N
倾角 = atan(80.0 / 480.5) = 9.46°
```

真实区间 **9.5°–11.7°**，两种都低于 14°，倾角这一项安全。

## 4. 缺失参数（拿到才能放行）

1. 喷嘴流量-压力曲线或实测 K 值——若 070 指 7.0 GPM@1000 psi，25 MPa 需求约 45–50 L/min，20 L/min 泵根本到不了 25 MPa；
2. 泵出口表压 + 喷嘴前压力实测——验证 11.4 MPa 管路损失；
3. 喷枪轴线到重心的垂直偏距 h；
4. 软管/接头/水枪额定压力 ≥ 25 MPa 的书面确认；
5. 整机实测推力曲线与悬停油门；
6. 单轴“11–13 kgf 连续”的准确口径；
7. 25 MPa 下 IMU 振动与机架应变实测；
8. 泵功率与系留箱供电余量（25 MPa 水力功率约 6.96 kW）。

## 5. 处置建议

1. 先做第 1、2 项（半天），判定 25 MPa 是否可达；
2. 拿到 h 前，25 MPa 只做悬停/短时测试，不做贴墙连续作业；
3. 倾角控制线维持 14°，不因“算出来 11.7°”放宽；
4. 振动单独跟进：17 MPa 已过 30 警告线，25 MPa 前先解决桨平衡与管缆耦合。
