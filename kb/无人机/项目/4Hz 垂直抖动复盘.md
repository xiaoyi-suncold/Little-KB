# 案例 001：4 Hz 垂直抖动（14S 四轴清洗机）

> 这是案例库的第一条真实案例，来源：`D:\ai\deekseep\jldh_fj\四轴清洗无人机_上下抖动诊断与调参报告.docx`（2026-10-28）。
> 按 [故障案例库](故障案例库.md) 的卡片格式整理。

## 基本信息

| 项 | 内容 |
| --- | --- |
| 机型 | 四轴清洗机（QUAD-X），CUAV-X7 飞控 |
| 固件 | ArduCopter V4.6.3（92b0cd78） |
| 动力 | 14S，`BATT_CAPACITY=3300`，PWM 电调（`MOT_PWM_TYPE=0`） |
| 数据 | DataFlash `.BIN` 2.27 MB（飞行段 106.8–198.2 s）+ 15.13 s 视频（1920×1088@30fps） |
| 现象 | 2.17 m 悬停 30 s，飞手报告「上下抖动」 |

## 现象（定量）

| 指标 | 数值 |
| --- | --- |
| 高度 | 2.141–2.193 m，峰峰 5.2 cm（几乎不动） |
| 油门输出 ThO | 0.041–0.195，4.00 Hz 摆动，方差占比 80.1% |
| 机体 Z 轴加速度 | −13.5～−6.5 m/s²，4 Hz 方差占比 **97.6%** |
| 视频独立验证 | 扣除相机运动后 3.98 Hz |
| 姿态 4 Hz 分量 | 横滚/俯仰仅 0.046°，方差占比 0.2–0.3% |
| 起飞前地面 | AccZ 标准差 0.34 m/s²，4 Hz 可忽略 |

结论：**抖的是推力，不是机体大幅位移；是控制回路产生的，不是结构共振。**

## 根因链

1. `MOT_THST_HOVER` 学到 0.125 → 油门-加速度增益 ≈ 9.81/0.125 ≈ 78.5 m/s²/单位（常规 0.5 悬停约 19.6）；
2. 默认 `PSC_ACCZ_P=0.5`、`PSC_VELZ_P=5.0` 使垂直环路指标 = 2.5/0.125 = **20**，约为常规机型（5.0）的 4 倍；
3. 叠加 10 Hz 控制周期、约 60 ms 电机/桨响应、EKF 延时，总延迟 150–200 ms → 4 Hz 处相位 180°；
4. 低油门端推力非线性把振幅限制在 0.04–0.19，形成**稳定极限环**。

三个放大因素：
- `MOT_THST_HOVER=0.125` **低于** `MOT_SPIN_MIN=0.15`（参数矛盾），悬停段 69% 油门样本低于 0.15；
- `MOT_HOVER_LEARN=2` 在飞行中把悬停油门从 0.200 一路学到 0.125，越学越低；
- 四电机对角输出差约 75 µs（C1/C2≈1410，C3/C4≈1338），`ATC_RAT_YAW_I` 均值 0.047、`AHRS_TRIM` 1.25°/0.55°，说明重心/电机座/飞控水平有偏置；
- 高度源用 GPS（`EK3_SRC1_POSZ=3`，VAcc≈2.2 m）做 2 m 高度保持；气压计受桨洗污染（BARO 与 EKF 差约 1 m）。

## 已排除

姿态环不是主因（角速率跟踪误差 0.005 量级）；不是飞手打杆（RCIN 稳定）；不是桨严重不平衡（地面振动低、频谱是单峰而非宽带）；不是电机失效（四路相关 0.97，未触发推力限幅）。

## 处置方案（报告表 5 A 组）

| 参数 | 当前 | 建议 |
| --- | --- | --- |
| `MOT_THST_HOVER` | 0.125 | 0.12（按作业重量实测） |
| `MOT_HOVER_LEARN` | 2 | 0（冻结学习） |
| `MOT_SPIN_MIN` | 0.15 | 0.08（地面实测 +0.02） |
| `MOT_SPIN_ARM` | 0.10 | 0.05 |
| `PSC_ACCZ_P` | 0.5 | 0.15 |
| `PSC_VELZ_P` | 5.0 | 2.0 |
| `PSC_ACCZ_I` | 1.0 | 0.30 |
| `PSC_ACCZ_IMAX` | 800 | 400 |
| `PSC_JERK_Z` | 5 | 3 |

根本手段：把作业重量下的悬停油门拉回 0.35–0.50（换小桨/降电压/减重），否则只是让控制器在低油门端勉强工作。

## 结果（2026-11-02 补：已用另外三份日志验证）

用 `scripts/df_bin_report.py`（pymavlink + numpy FFT）解析 `飞行日记\` 全部 4 份日志：

| 日志 | 时长 | 参数状态 | 悬停段 | 3–6 Hz 残余峰 | 幅度 |
| --- | --- | --- | --- | --- | --- |
| 10:59:54 | 198 s | 原始（HOVER 0.20，PSC 0.5/5.0，ACCEL 10） | 未起飞 | — | — |
| 15:28:54 | 315 s | **修订版**（HOVER 0.20，PSC 0.25/2.5，I 0.5，ACCEL 15，LEARN 0） | 64–89 s，2.86 m，σ=6 mm | 3.68 Hz | **0.118 m/s²** |
| 15:35:15 | 774 s | HOVER 0.35，EXPO 0.65，PSC 0.25/2.5 | 123–148 s，2.99 m，σ=9 mm | 3.47 Hz | 0.150 m/s² |
| 15:50:13 | 1904 s | HOVER 0.35，PSC 0.25/2.5，I 0.6 | 1605–1630 s，1.54 m，σ=0 | 5.8 Hz | 0.001 m/s²（噪声底） |

**结论**：修复有效。4 Hz 幅度从 2.82 m/s² 降到 0.12–0.15 m/s²（约原来的 **4–5%**），高度标准差 6–9 mm。残余峰在 3.5–3.7 Hz，属于降增益后的低频残余，不再是等幅极限环。

16 MB 那份日志（1904 s、25 次模式切换）里已经没有 3–4 Hz 的集中能量，说明后续飞行稳定。

原始 4 Hz 的 2.82 m/s² 对照：同一指标在 15:28 日志中为 0.118。

## 可复用结论

1. 4 Hz 抖动先看 `CTUN.ThO` 与 `IMU.AccZ` 的频谱，而不是先调 PID；
2. 悬停油门是**工作点**，不是调参旋钮；`MOT_THST_HOVER < MOT_SPIN_MIN` 是硬性矛盾；
3. `MOT_HOVER_LEARN=2` 在动力过剩的飞机上会加剧问题；
4. 判断“结构共振还是控制极限环”：看频率是否随油门移动、地面静止时是否存在。
