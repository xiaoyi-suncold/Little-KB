# 自制无人机法规与安全合规核验

> 检索日期：2026-10-30。中国部分以中国政府网、交通运输部、民航局和国家标准平台为主；FAA/EASA 仅作境外官方参考。实际起飞前须再查 UOM、当地空域与临时通告。

## 一、中国：自制不免除登记与运行要求

### 1. 先确认航空器类别和任务性质

《无人驾驶航空器飞行管理暂行条例》按性能分为微型、轻型、小型、中型和大型。重量不是唯一判据，还涉及最大平飞速度、真高、空域保持能力、可靠被监视能力和人工介入能力；改装后应按改装后的类别管理。

还要区分：个人还是单位、是否经营、是否农用常规作业、是否飞越人群/投放物品/集群/超视距。不要仅凭“自己组装”“做测试”推断无需许可。

### 2. 设计与适航

条例第八条：中型、大型系统的设计、生产、进口、飞行和维修应依法取得适航许可；微型、轻型、小型的设计生产及组装拼装无需取得该适航许可，但仍须符合产品质量法规和强制性国家标准。

因此，“小型自造通常无需型号合格审定”不等于“没有安全、登记和运行要求”。

### 3. 实名登记、激活与更新

- 条例第十条要求所有者依法实名登记；CCAR-92 第92.205条等规定通过 UOM 登记并取得登记标志。
- 民航局 UOM 是实名登记、操控员执照、空域查询、飞行活动申请和运营管理的官方入口：[https://uom.caac.gov.cn/w/main](https://uom.caac.gov.cn/w/main)。
- 改装导致空域保持、可靠被监视、速度或高度等性能/参数改变时，应按要求更新信息；所有权变化、报废等按规则办理注销。
- GB 46761—2025《民用无人驾驶航空器实名登记和激活要求》与 GB 46750—2025《民用无人驾驶航空器系统运行识别规范》已于 **2026-05-01** 实施。自造系统应核实登记、激活和运行识别的具体实现责任，不要假定开源飞控默认就满足。

### 4. 操控员与运营资质

- 条例第十六条：操控小型、中型、大型无人机原则上应取得相应操控员执照，条例规定的例外另计。
- 微型、轻型无需操控员执照，但须熟练掌握机型和风险规则；轻型进入管制空域还有额外培训要求。
- 条例第十一条和 CCAR-92 对“以单位名义运行”的运营合格证有独立要求，不能把个人娱乐飞行规则套到单位作业。
- 经营性飞行以及条例规定的部分非经营性飞行还涉及责任保险，按任务性质核验。

### 5. 空域与飞行活动申请

条例第十九条明确：真高 120 米以上以及列举的机场、边境、涉密、重要设施等区域上方属于管制空域；管制空域以外为微型、轻型、小型的适飞空域。适飞不等于所有行为都无需申请。

条例第三十一条列出适飞空域内一般飞行等免申请情形，同时明确：通过通信基站/互联网中继、运载危险品或投放物品、飞越集会人群、在移动交通工具上操控、分布式操作或集群飞行等情形仍须申请。获批飞行还涉及起飞前确认。

**起飞前动作：**在 UOM 查最新空域和属地通告 → 核对机型/人员/运营资质 → 判断是否需要活动申请 → 检查运行识别、围栏和应急预案。

### 6. 运行识别与飞行检查

CCAR-92 要求按规定报送身份和飞行动态数据，运行时不得关闭报送功能。GB 46750—2025 进一步规定广播式与网络式运行识别的信息内容、链路和接收处理要求，民航局官方解读明确系统应在运行全过程主动报送身份、位置、速度和状态等信息。

飞行前还应完成：注册与标识、气象、场地、机体、桨与电池、通信导航、电子围栏、失控返航和应急预案检查。测绘、涉密拍摄、无线电使用等另有专门规定。

## 二、美国 FAA：按娱乐或 Part 107 分开判断

官方要点（仅作境外参考）：

- 需要注册的无人机通过 FAADroneZone 登记；仅满足“低于 250 g 且按有限娱乐例外飞行”的无人机有登记例外。用于 Part 107 的无人机不能按娱乐例外处理。
- 娱乐飞行须完成 TRUST 并携带证明，遵守 FAA 认可 CBO 安全准则、视距内、让行有人机、空域授权和 Remote ID 等要求。
- 非娱乐的小型无人机默认按 14 CFR Part 107 判断；FAA 明确提醒“没有报酬”并不必然等于娱乐飞行。
- 管制空域使用 LAANC 或 DroneZone 获取授权；不要只凭地图 App 的非官方说明。

官方入口：[Recreational Flyers](https://www.faa.gov/uas/recreational_flyers)、[Registration](https://www.faa.gov/uas/getting_started/register_drone)、[Part 107](https://www.ecfr.gov/current/title-14/chapter-I/subchapter-F/part-107)。

## 三、欧盟 EASA：Open / Specific / Certified

- Open 类用于多数低风险活动，细分 A1/A2/A3；官方概括为“飞越非聚集人群”“接近人员”“远离人员”三种场景，各自有航空器等级、培训和距离要求。
- Open 类可使用带 C0–C4 标识的无人机，也覆盖符合条件的 privately built 自用航空器。EASA 特别说明：privately built 指为个人自用而建造，不等同于购买整套 ready-to-assemble 套件。
- 超出 Open 条件时进入 Specific，通常涉及运行风险评估和主管机关授权；高风险任务进入 Certified。
- 还需核验操作者注册、成员国地理区域和最新 Easy Access Rules，不能只背统一的重量/高度数字。

官方入口：[Open Category](https://www.easa.europa.eu/en/domains/drones-air-mobility/operating-drone/open-category-low-risk-civil-drones)、[Easy Access Rules](https://www.easa.europa.eu/en/domains/civil-drones/easy-access-rules)。

## 四、制作方合规清单

- [ ] 记录设计重量、速度、真高、空域保持与运行识别能力，确定改装后的类别。
- [ ] 确认所有者实名/激活、机身标识和参数更新流程。
- [ ] 确认操控员、单位运营和保险要求。
- [ ] 在官方平台查空域与临时限制，判断是否需飞行活动申请。
- [ ] 验证运行识别、电子围栏、失效保护和事件报告流程。
- [ ] 保存设计、测试、维护和每次改装记录。
