## 二、来源分级与使用规则

1. **A1：法规、标准、官方飞控文档、源码**。用于确定流程、参数语义和合规要求。
2. **A2：官方地面站、日志工具、硬件厂商手册与测试表**。用于确定工具用法和具体硬件条件。
3. **实测数据**。本机日志、拉力台、万用表和功率计结果，用于决定本机最终参数；官方示例值不能替代实测。
4. **不采用为结论**：论坛帖、短视频、无来源参数表。它们最多用于发现搜索关键词。

三条硬规则：

- 先记录飞控类型、固件版本、机型、桨径、动力与载荷，再查参数；`main`/`next` 文档不一定等于本机稳定版。
- 不跨机复制 PID、滤波、油门和失效保护值。官方给出的初始值也只用于其说明的机型范围。
- 每次只改一类变量，保存改前参数和日志，按“短试飞 → 落地检查 → 日志复核”闭环。

- [Tuning Process Instructions](https://ardupilot.org/copter/docs/tuning-process-instructions.html)：多旋翼调参总流程。
- [Setting the Aircraft Up for Tuning](https://ardupilot.org/copter/docs/setting-up-for-tuning.html)：调参前初始设置。
- [Initial Tuning Flight](https://ardupilot.org/copter/docs/initial-tuning-flight.html)：初始试飞与振荡处置。
- [Dynamic Harmonic Notch Filters](https://ardupilot.org/copter/docs/common-imu-notch-filtering.html)：动态谐波陷波。
- [AutoTune](https://ardupilot.org/copter/docs/autotune.html)：自动调参条件、过程和保存逻辑。
- [Measuring Vibration](https://ardupilot.org/dev/docs/common-measuring-vibration.html)：VIBE、削波和轴向排查。
- [ArduPilot WebTools](https://firmware.ardupilot.org/Tools/WebTools/)：官方网页分析工具入口。
- [Methodic Configurator](https://ardupilot.github.io/MethodicConfigurator/)：分阶段配置工具。

### PX4 / QGroundControl

- [Multicopter PID Tuning Guide](https://docs.px4.io/main/en/config_mc/pid_tuning_guide_multicopter)：速率环、姿态环及推力非线性。
- [Autotune](https://docs.px4.io/main/en/config/autotune.html)：自动调参与故障处置。
- [MC Filter Tuning & Control Latency](https://docs.px4.io/main/en/config_mc/filter_tuning.html)：静态/动态陷波、低通和延迟。
- [Flight Review](https://docs.px4.io/main/en/log/flight_review)：ULog 分析入口。
- [QGroundControl Tuning](https://docs.qgroundcontrol.com/master/en/qgc-user-guide/setup_view/tuning_px4.html)：地面站调参界面。
- [QGroundControl Sensors](https://docs.qgroundcontrol.com/master/en/qgc-user-guide/setup_view/sensors_px4.html)：传感器校准。
- 注意：`main` 是开发版文档；实际操作应在页面版本选择器切换到本机稳定版本。

### Betaflight / INAV

- [Betaflight PID Tuning Guide](https://betaflight.com/docs/wiki/guides/current/PID-Tuning-Guide)：P/I/D/FF 与电机发热风险。
- [DShot RPM Filtering](https://www.betaflight.com/docs/wiki/guides/current/DSHOT-RPM-Filtering)：双向 DShot、极对数、错误率和滤波验证。
- [PID Tuning Tab](https://www.betaflight.com/docs/wiki/app/pid-tuning-tab)：滑块与 Profile 的官方语义。
- [Betaflight Releases](https://github.com/betaflight/betaflight/releases)：先确认版本，再读对应 Tuning Notes。
- [INAV 官方文档](https://inavflight.github.io/)：按版本查阅调参、导航、Blackbox 和 Failsafe。
- [INAV Navigation PID Tuning (FW)](https://inavflight.github.io/next/pid-tuning/navigation-pid-tuning-fw)：主导航调参前置条件。
