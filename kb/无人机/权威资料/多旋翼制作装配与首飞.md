# 多旋翼制作、装配与首飞工程清单

> 来源：ArduPilot、PX4、QGroundControl 官方文档及厂商原始测试资料，检索日期 2026-10-30。本文用于设计与检查，不替代具体飞控、电调、电机和电池制造商手册。

## 结论

专业制作不是“买齐零件—焊起来—刷默认参数”。应按：

**需求与载荷 → 动力/结构/电气设计 → 台架验证 → 装配与无桨测试 → 初始稳定飞行 → 滤波/PID → 任务载荷与失效保护 → 出厂记录**

逐步放行。任何一步发现方向、供电、振动或控制余量异常，都返回上一步。

## 1. 需求与 BOM：先冻结工作点

至少明确：最大起飞重量、任务载荷及位置、悬停/巡航时间、最大速度与风况、桨径限制、噪声与防护要求、供电制式、通信链路、失效保护策略、法规类别。

BOM 不只列型号，还要列接口与验证资料：

- 机架尺寸、轴距、桨间/桨与机身间隙、重心范围和结构刚度。
- 电机 KV、适用电压、持续/峰值电流、推荐桨和厂家测试表。
- 电调协议、电压/电流限制、遥测能力、PWM 行程或数字协议配置。
- 电池串数、容量、持续放电与连接器；电源模块/PDB 的测量与供电能力。
- 飞控处理器、IMU、减振安装、固件支持；GNSS/罗盘、接收机、数传和蜂鸣器接口。

## 2. 动力系统：用原始测试表选型，用实测定案

厂商测试表要按**相同电压、桨、油门点和测试条件**读取。至少提取：拉力、电流、功率、RPM、力效和温度。不要只拿“最大拉力”作为整机选型依据。

建议流程：

1. 由总重与控制余量确定每轴所需悬停和最大连续推力。
2. 在厂家表中找到悬停与最大连续工作点，检查电流、温升和电调/电池负担。
3. 核算全机总电流和配电热负荷，保留姿态控制余量，避免长期贴近输出饱和。
4. 专业机型用拉力台测量本机电机—电调—桨组合，获得推力线性与工作区间。ArduPilot 官方明确指出，专业调参不应盲信厂家推力曲线。
5. 首飞后结合悬停油门、各电机输出、振动和温度复核；载荷改变要重新评估。

原始数据入口：[T-Motor 产品资料](https://uav-cn.tmotor.com/)、[APC 技术资料](https://www.apcprop.com/technical-information/)。具体数值必须回到选定型号页面，不使用第三方转录表。

## 3. 结构与减振

- 飞控尽量靠近重心、正面朝上、箭头朝前；偏离默认朝向时必须在固件中设置实际安装方向。
- PX4 官方说明：IMU 明显偏离重心时，应按版本配置 `EKF2_IMU_POS_X/Y/Z`，否则位置/速度估计会围绕 IMU 而非重心产生附加修正。
- 机臂和电机座紧固，桨夹同心，电机轴无弯曲，轴承无异常；螺旋桨无裂纹并做平衡。
- 优先消除振源，再做飞控减振。过软减振和过软机架都会增加控制延迟；不能把“越软越好”当原则。
- 飞控线束使用柔性线和应力释放，不能让拉紧的线束绕过减振垫形成硬连接。
- GNSS/罗盘远离大电流线、电调和磁干扰源；动力电源线按官方建议短而整齐，必要时双绞。

## 4. 电气与接线

### 供电

- 电源模块给飞控提供合规、稳定的供电，并按需测量总电压/电流；飞控的 PWM 信号排不等于大电流电源排。
- 电调/电机从动力电池经 PDB 或相应配电供电；舵机、图传和载荷按各自电流要求独立核算 BEC/供电。
- 核对每个连接器的额定电流、极性和防反接；上电前测短路、焊点、绝缘和极性。
- 电压读数用万用表比对，电流读数用功率计/分流器在有意义的工作电流附近校准。低电流下不准的传感器不能仅靠零点校准解决。

### 信号

- 电调信号和信号地按手册连接；电机输出编号必须与机架混控一致。
- PX4 官方建议优先使用低延迟的 FMU/AUX 输出；DShot 只能用于支持的输出组，具体以飞控硬件文档为准。
- 传统 PWM 电调可能需要行程校准；DShot/CAN 等数字电调不需要按 PWM 方式校准。任何电机测试先拆桨。

## 5. 固件配置与无桨测试

按顺序执行并记录：

1. 刷入与硬件匹配的固件，备份默认参数。
2. 选择正确机架/混控，设置飞控与外部罗盘朝向。
3. 校准加速度计、陀螺仪、罗盘、水平、遥控器和电源监测。
4. 配置接收机协议、通道映射、飞行模式、解锁/上锁和紧急停桨。
5. 无桨逐一做电机测试：编号、转向、启动一致性、振动、遥测 RPM/错误率。
6. 按官方电机测试设置最小启动和连续运转区间；不能用“别人同尺寸机子的值”。
7. 配置并验证电池低电量、遥控断链、地理围栏和必要失效保护。
8. 保留完整 Pre-Arm 检查。官方要求解决报警原因，而不是长期关闭检查。
9. 下载并保存参数快照，记录固件版本、BOM、接线图和测试人/日期。

## 6. 首飞与逐步放飞

### 首飞前检查

- 场地合法、空旷、低风，人员与财产保持安全距离；有明确中止和灭火/电池处置方案。
- 桨型号、旋向、紧固和完整性正确；整机重心在允许范围，载荷不晃动。
- 电池电压与安装可靠，遥控/数传/定位正常，Home 与返航逻辑已理解。
- 再确认机架类型、电机顺序和方向；这是最容易造成瞬间翻机的项目。

### 飞行放行顺序

1. 在 Stabilize 或相应基础模式做极短离地—落地，验证解锁/上锁和基本控制。
2. 低高度悬停，小角度横滚/俯仰输入；任何持续振荡、异常声音或控制方向错误立即落地。
3. 验证 AltHold/定高，再验证 Position/Loiter；不要一次把所有自动模式打开。
4. 短飞行后检查电机、电调、电池、连接器温度和日志，再逐步增加动作幅度。
5. 姿态控制稳定后，依次验证返航、低电量、断链和围栏；先在安全条件下做可控测试。
6. 最后安装/加载真实任务载荷，重新检查重心、动力余量、振动与调参。

## 7. 出厂记录模板

每架机至少保存：唯一机号、BOM 与序列号、接线图、固件版本、全量参数、传感器校准、动力测试、振动/频谱、首飞日志、失效保护测试、载荷状态、维护与更换件记录。后续任何改桨、改电机、改载荷或改重心都应生成新版本，而不是覆盖旧记录。
