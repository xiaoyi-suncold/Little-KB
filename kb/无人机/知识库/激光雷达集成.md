# 激光雷达集成（时间同步 / 外参 / 避障）

> 光伏巡检、贴近飞行、GPS 拒止环境都绕不开雷达。难点不在装上去，而在**时间对齐**与**外参准确**。

## 1. 三条时间同步路线

| 方式 | 精度 | 条件 | 适用 |
| --- | --- | --- | --- |
| PPS + GPRMC（GPS 授时） | µs 级 | 雷达支持 GPS 接口，飞控有 PPS 输出 | 户外建图、RTK 融合 |
| PTP / gPTP（IEEE 1588） | µs 级 | 交换机支持、雷达与主机同一时钟域 | 车载/机载以太网雷达 |
| 主机接收时间戳 | ms 级 | 无额外硬件 | 只看障碍物、不建图 |

**判据**：建图要求 <1 ms 同步误差；避障可以放宽到 10 ms。同步没做好，点云会"糊"、建图会重影，而且很难事后补救。

Livox 的 MID-360 等型号支持 PTP/gPTP 与 GPS 授时，需要在网页端把同步模式切到对应选项；RoboSense 的接口文档同样给出 PPS+GPRMC 的接线与语句格式。**不同厂商、不同型号的同步方式不一样，必须查对应型号手册**。

## 2. 外参（安装位置与姿态）

雷达输出的点云在**雷达坐标系**，要转到机体/世界坐标系，需要 6 个量：

```
x, y, z（相对重心，米）  +  roll, pitch, yaw（相对机体，度）
```

标定方法，按精度从低到高：

1. **卷尺 + 水平仪**：误差 1–2 cm / 1°，只够避障；
2. **地面控制点**：已知坐标的靶标，反算外参，适合建图；
3. **手眼标定/优化**：用多帧点云与已知平面联合优化，精度最高。

外参错了的典型表现：点云地面倾斜、直线变弯、建图闭环对不上。**先标外参，再谈算法。**

## 3. 安装要点

- 远离桨洗与喷水雾（清洗机尤其），镜头加遮光罩/防滴罩；
- 视场不被机臂、喷杆、起落架遮挡——装之前用 CAD 或纸板模拟一遍；
- 减震：雷达对高频振动敏感，但**不能太软**，否则会引入低频摆动；
- 电源独立、地与飞控单点连接，避免电机噪声串入以太网；
- 线缆留滴水弯，接头朝下。

## 4. 数据链与驱动

```
雷达 → 以太网/UDP → 机载计算机（ROS/ROS2）→ 驱动（Livox SDK2 / RS-LiDAR / Hesai SDK）→ 点云话题
```

- Livox：`livox_ros_driver2`，MID-360 内置 IMU，可直接跑 FAST-LIO；
- RoboSense：`rslidar_sdk`；
- Hesai：`HesaiLidar_ROS_2.0`。

机载计算机再通过 MAVLink 把障碍物距离/方向送给飞控。

## 5. 与飞控的对接现实

| 飞控 | 避障接口 | 说明 |
| --- | --- | --- |
| ArduPilot | `PRX_*` + `AVOID_*` | 支持 MAVLink 距离传感器、伴飞计算机送障碍物；支持 BendyRuler/Dijkstra 绕障 |
| PX4 | Collision Prevention | 通过 MAVLink `OBSTACLE_DISTANCE` 或伴飞计算机 |

**大疆禅思 L2** 是封闭生态：主要配 M300/M350 + DJI Pilot 2 + 大疆智图，**没有 ArduPilot/PX4 的官方驱动**。想在自己做的六轴机上用 L2，基本走不通；替代是 Livox / RoboSense / Hesai + 开源驱动。

## 6. 选型参考

| 型号 | 特点 | 适用 |
| --- | --- | --- |
| Livox MID-360 | 360° 水平、约 40 m、内置 IMU、便宜 | 建图、避障、室内 |
| Livox Avia | 更远、精度更高 | 测绘 |
| RoboSense Helios/Airy | 机械式、成熟 | 车载/机载建图 |
| Hesai XT32/XT16 | 高线束、远距 | 电力巡检 |
| DJI L2 | 与大疆生态深度绑定 | 只用大疆飞机时 |

## 7. 集成检查清单

- [ ] 同步模式已在雷达端切换并验证（看点云时间戳）
- [ ] 外参实测并写入驱动/标定文件
- [ ] 视场无遮挡，镜头防尘防水
- [ ] 供电独立，接地单点
- [ ] 机载计算机与飞控时间同步（`SYS_TIME`/chrony）
- [ ] 避障参数（`PRX_*`/`AVOID_*`）单独测试，先悬停再飞行
- [ ] 记录一次完整标定与测试日志
