# 法规与空域要点（中国）

> 设计阶段就要把法规当约束，不要等造完才发现飞不了。以下为工程视角的要点梳理，**以官方最新发布为准**。

## 1. 为什么设计阶段要看

- 最大起飞重量决定分类，分类决定执照与空域要求；
- 作业场景（城市/农田/光伏电站）决定是否需要额外审批；
- 实名登记与识别模块影响 BOM 与结构空间；
- 超重/超尺寸可能改变运输与起降方案。

## 2. 分类与实名

按现行《无人驾驶航空器飞行管理暂行条例》（2024 年 1 月 1 日施行）的口径，微型/轻型/小型/中型/大型按**空机重量、最大起飞重量、速度**等指标划分，管理要求逐级提高。

工程含义：

- 微型/轻型：限制多但门槛低，适合消费与轻作业；
- 小型及以上：通常需要实名登记、操控员执照、空域申请；
- 具体阈值与豁免条款以主管部门最新文件为准，设计输入应记录所依据的文件版本与日期。

## 3. 空域与飞行活动

- 适飞空域内（常见口径为真高 120 m 以下、非管制区域）按简化流程；
- 管制空域、机场净空区、重要设施周边需申请或禁止；
- 作业类飞行通常需要提前报备计划，跨区作业要按当地要求；
- 夜间、超视距、集群飞行有额外条件。

## 4. 对设计的直接影响

| 法规要求 | 设计响应 |
| --- | --- |
| 实名登记与识别 | 预留识别模块空间与供电 |
| 最大重量限制 | 结构轻量化、模块化载荷 |
| 高度限制 | 围栏默认高度、飞控限高策略 |
| 视距内运行 | 图传与链路预算、避障 |
| 噪声与扰民 | 桨叶选型、转速上限 |
| 作业安全 | 失效保护、降落伞（大机型） |

## 5. 作业现场合规清单

- [ ] 机型已完成实名登记
- [ ] 操控员具备对应等级资质
- [ ] 空域/计划已报备（如需）
- [ ] 作业区下方与周边无无关人员
- [ ] 围栏与限高已按场地设置并测试
- [ ] 保险有效
- [ ] 飞行记录与日志留存

## 6. 设计文档里要留的痕迹

- 依据的法规名称、条款、版本日期；
- 机型分类判定的计算过程（重量、速度）；
- 与法规冲突时的替代方案（减重、限高、改场景）。

## 说明

法规会更新，阈值与流程以中国民用航空局及地方主管部门最新公告为准。本文只提供工程侧的映射关系，不作为合规结论。

## 来源

- 《无人驾驶航空器飞行管理暂行条例》（国务院、中央军委，2024-01-01 施行）
- 中国民用航空局（CAAC）无人驾驶航空器相关管理规定
