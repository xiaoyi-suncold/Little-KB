# 动力系统匹配（设计导向）

> 目标：给定起飞重量、续航、作业环境，反推出桨、电机、电调、电池的组合，并说清每一环的取舍。
> 本文所有公式都能手算；标「实测」的部分必须上机验证。

## 1. 从需求到功率：动量理论

悬停时旋翼把空气向下加速，理想功率（Froude 动量理论）：

```
P_ideal = T^(3/2) / sqrt(2 · ρ · A)
```

- `T` 总拉力（N）= 起飞质量 × 9.81
- `ρ` 空气密度（海平面 1.225 kg/m³，2000m 约 1.0）
- `A` 总桨盘面积 = 桨数 × π·(D/2)²，`D` 为桨径（m）

真实悬停功率还要除以品质因数 `FM`（小桨 0.5–0.6，大桨 0.65–0.75）：

```
P_hover = P_ideal / FM
```

**例**：25 kg 六轴，28 寸桨（0.711 m），A = 6×π×0.355² = 2.38 m²
→ P_ideal = (245)^1.5 / sqrt(2×1.225×2.38) = 3835 / 2.41 ≈ 1590 W
→ 取 FM 0.65，P_hover ≈ 2.45 kW，单轴约 408 W。

## 2. 三个决定性比值

| 比值 | 定义 | 工业多旋翼常用区间 | 越界的后果 |
| --- | --- | --- | --- |
| 推重比 T/W | 最大总拉力 / 起飞重量 | 1.6–2.2 | <1.5 抗风差、掉高；>2.5 悬停油门过低、姿态环难整定 |
| 桨盘载荷 W/A | 起飞重量 / 总桨盘面积 | 25–60 kg/m² | 过高：下洗强、地效敏感、噪声大、效率低 |
| 电机功率密度 | 单轴持续功率 / 电机自重 | 3–6 W/g（大机） | 过高：温升快、磁钢退磁 |

T/W 与悬停油门的关系不是线性的：ArduPilot 用 `MOT_THST_EXPO` 把油门指令映射到推力，实测悬停油门 `CTUN.ThO` 才是最终依据。经验值：T/W≈2.0 时 ThO 常在 0.25–0.35；若实测 ThO 只有 0.15 而 T/W 实测只有 1.4，说明 `MOT_THST_EXPO` 或电压补偿设错了。

## 3. 选型顺序（不要反过来做）

1. **定起飞重量**：空机 + 电池 + 载荷（水箱按 1 L = 1 kg）+ 10% 余量。
2. **定桨径**：受机架尺寸与运输限制；28–32 寸是 25–40 kg 级常用档。
3. **按桨盘载荷校核**：W/A 落在 25–60 kg/m²，否则改桨径或减重。
4. **选电机 KV**：`KV ≈ 目标转速 / 电压`。大桨低 KV（如 28 寸配 100–170 KV @ 12S）。
5. **查电机拉力表**：在目标电压下取「50% 油门拉力 × 轴数 ≥ 1.6 × 起飞重量」。
6. **选电调**：持续电流 ≥ 单轴最大电流 × 1.3，峰值留 1.5 倍；优先 DroneCAN/DShot 带电调回传。
7. **选电池**：能量 `E = P_hover × t / (η × DoD)`，`η≈0.85`，`DoD` 取 0.8。

**例（25 kg 六轴，悬停 2.45 kW，目标 20 min）**：E = 2450 W × 0.333 h / (0.85×0.8) ≈ 1200 Wh → 12S 27 Ah 或 14S 23 Ah。

## 4. 电芯数与线损

同样功率下，电压越高电流越小，`I²R` 线损按平方下降：

```
I = P / V        P_loss = I² · R_wire
```

12S→14S 电流降 14%，线损降 26%。但电芯越多，BMS/充电器/绝缘要求越高。工业机常见 12S、14S、18S 三档。

**必须自洽**：`BATT_ARM_VOLT`、`BATT_LOW_VOLT`、`BATT_CRT_VOLT`、`MOT_BAT_VOLT_MAX/MIN` 必须指向同一个电芯数。四轴表是 12S 自洽（50.4/44.3/43.2/42），六轴表的 BATT 阈值指向 16S（66.5/64.8/63）而 `MOT_BAT_VOLT_MAX=75.6` 指向 18S——这是**同一张表里两套假设**，必须先量电芯。

## 5. ArduPilot 侧的关键参数

| 参数 | 作用 | 设定方法 |
| --- | --- | --- |
| `MOT_THST_EXPO` | 油门→推力曲线形状 | 大桨/低盘载取 0.5–0.7；高盘载/小桨取 0.75–0.9。设错会让中位附近过灵敏或发闷 |
| `MOT_THST_HOVER` | 悬停油门前馈 | 读稳定悬停时 `CTUN.ThO` 平均值，开 `MOT_HOVER_LEARN=2` 可自动学 |
| `MOT_SPIN_MIN` | 飞行中最小油门 | 比悬停油门低 0.05–0.08，保证不丢转速 |
| `MOT_SPIN_ARM` | 解锁怠速 | 略低于 `MOT_SPIN_MIN`，地面能可靠起转即可 |
| `MOT_PWM_MIN/MAX` | 输出行程 | 与电调标定一致（常见 1000–2000） |
| `BATT_VOLT_MULT` / `BATT_AMP_PERVLT` | 模拟电源模块的电压/电流标定 | 见下 |

## 6. 电源模块校准（雷讯 CUAV 官方流程）

CUAV 文档把电源模块分成两类：

- **CAN 系列（DroneCAN）**：电压、电流、电量在模块内部计算并做过工厂校准，飞控侧不需要再标定，只需选对 `BATT_MONITOR` 类型。
- **模拟系列（HV_PM、7-Nano 配套等）**：必须标定——
  1. 给模块稳定电压，用万用表实测并输入，系统自动修正电压乘数（`BATT_VOLT_MULT`）；
  2. 接稳定负载，用高精度电流表实测并输入，系统自动修正安培/伏特（`BATT_AMP_PERVLT`）；
  3. 再设 `BATT_CAPACITY`（mAh），否则电量百分比与低电量保护都不可信。

对应到这两台机：四轴 `BATT_MONITOR=8`（DroneCAN），六轴 `BATT_MONITOR=4`（模拟 ADC，`BATT_VOLT_PIN=16`、`BATT_CURR_PIN=17`、`BATT_VOLT_MULT=31.19`、`BATT_AMP_PERVLT=60`）——六轴这套是**必须标定**的。来源：[雷讯·电源监测器](https://doc.cuav.net/controller/apm/config/pm.html)。

## 7. 常见设计错误

1. 先买电机再算桨 → 拉力表对不上，只能靠限油门飞行。
2. 只算最大拉力不算悬停功率 → 电池选小，10 分钟就没电。
3. 忽略电压补偿：满电 4.2 V/cell 与 3.7 V/cell 输出差异可达 15%，不设 `MOT_BAT_VOLT_MAX/MIN` 会出现「满电窜、低电软」。
4. 电调余量不足：持续电流按最大拉力算，但清洗机长时间悬停 + 水泵负载，热积累比峰值更致命。
5. 悬停油门被压到 0.15 以下：姿态环几乎无余量，一遇阵风就顶到输出饱和。

## 8. 设计校核清单

- [ ] T/W 在 1.6–2.2，且用实测拉力表算
- [ ] W/A 在 25–60 kg/m²
- [ ] 悬停功率 ≤ 电池可持续放电功率（`C 数 × 容量`）
- [ ] 单轴最大电流 ≤ 电调持续电流 / 1.3
- [ ] 电芯数与所有电压阈值自洽
- [ ] 悬停油门落在 0.25–0.45（超出要查 expo 与标定）
- [ ] 电源模块已标定，`BATT_CAPACITY` 与实物一致
