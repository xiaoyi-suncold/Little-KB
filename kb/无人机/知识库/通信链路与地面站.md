# 通信链路与地面站

> 链路是「看不见的动力系统」：它断了，飞机再好也回不来。

## 1. 三条链路，各管一段

| 链路 | 频段（常见） | 传什么 | 断了会怎样 |
| --- | --- | --- | --- |
| 遥控（RC） | 2.4 GHz / 900 MHz | 杆量与模式开关 | 触发 `FS_THR_ENABLE` |
| 数传（Telemetry） | 433 / 915 MHz、4G | MAVLink 状态与指令 | 触发 `FS_GCS_ENABL`（若启用） |
| 图传（Video） | 2.4 / 5.8 GHz、4G | 图像 | 失去目视辅助，不影响控制 |

三者相互独立才叫冗余。用同一个 2.4G 模块同时做 RC 和图传，是最常见的单点故障。

## 2. 链路预算（先算再做）

自由空间损耗（Friis）：

```
L(dB) = 32.44 + 20·log10(f_MHz) + 20·log10(d_km)
```

链路余量：

```
Margin = P_tx + G_tx + G_rx − L − Sensitivity
```

工程要求：**余量 ≥ 10 dB（保守 20 dB）**，因为植被、机身遮挡、天线姿态损失会吃掉 10–20 dB。

**例**：433 MHz、发射 2 W（33 dBm）、两端天线各 2 dBi、接收灵敏度 −120 dBm、距离 5 km
→ L = 32.44 + 20×log10(433) + 20×log10(5) ≈ 32.44 + 52.7 + 14 = 99.1 dB
→ Margin = 33 + 2 + 2 − 99.1 + 120 = 57.9 dB（非常充裕）

同样是 5 km、2.4 GHz、100 mW（20 dBm）、0 dBi：
→ L ≈ 32.44 + 67.6 + 14 = 114 dB → Margin = 20 + 0 + 0 − 114 + 120 = 26 dB（可用但余量一般）

## 3. MAVLink 带宽

每条消息都有固定开销（帧头 + CRC）。`SR*_` 参数控制每个串口各类消息的发送频率（Hz）：

| 参数 | 消息类别 |
| --- | --- |
| `SR1_POSITION` | 位置/姿态 |
| `SR1_EXTRA1` | 姿态、`ATTITUDE` |
| `SR1_EXTRA2` | `VFR_HUD` |
| `SR1_EXTRA3` | 电池、GPS 原始 |
| `SR1_PARAMS` | 参数列表 |
| `SR1_RAW_SENS` | 原始传感器（很占带宽） |

粗算：一条 `ATTITUDE` ≈ 36 字节，10 Hz ≈ 360 B/s。把 `SR*_RAW_SENS` 开到 10 Hz 很容易打满 57600 波特（约 5.7 KB/s）。

**准则**：数传链路只保留控制与监控必需的消息；日志走机载 SD 卡，不走空口。

## 4. 天线与安装

- 极化一致：两端都用垂直极化，别一端横一端竖；
- 远离碳纤维与电池：遮挡会让方向图出现深零点；
- 双天线（分集）能显著改善姿态变化时的稳定性；
- 天线不要贴着机臂平行走线，避免与电源线耦合；
- 地面站天线越高越好，1 m 高度差在远距离上很值钱。

## 5. 干扰与共存

| 干扰源 | 影响 | 处置 |
| --- | --- | --- |
| 图传与 RC 邻频 | 遥控抖动、失控 | 拉开频点，或图传换 5.8G |
| 大功率电台/基站 | 数传丢包 | 换频段、加滤波、缩短距离 |
| 电机电调开关噪声 | 罗盘/接收机干扰 | 加磁环、远离电源线、双绞 |
| 多机同频 | 互相压制 | 跳频、时分、分配频点 |

## 6. 地面站该监控什么

- 链路质量（RSSI、丢包率）；
- 电压/电流与剩余电量；
- EKF 状态与 GPS 质量（卫星数、HDOP）；
- 振动（`VIBE`）；
- 模式与失效保护状态；
- 日志记录是否正常（起飞前确认）。

## 7. 失联策略设计

1. RC 失联 → `FS_THR_ENABLE`：作业区空旷用 RTL，室内/贴障用 Land；
2. 数传失联 → `FS_GCS_ENABL`：可设 Continue，但必须有「最长失联时间」兜底；
3. 图传失联 → 不影响控制，但要有人目视/预案；
4. 所有策略都要现场触发测试一次。
