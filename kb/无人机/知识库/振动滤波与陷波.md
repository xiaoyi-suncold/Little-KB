# 振动、滤波与陷波

> 多旋翼的「调不好」里，一半是振动问题。振动不进 PID，PID 才有意义。

## 1. 振动从哪来

| 来源 | 频率特征 | 处置 |
| --- | --- | --- |
| 桨不平衡 / 桨叶损伤 | 1× 转速（BPF）及谐波 | 动平衡、换桨 |
| 电机轴承磨损 | 高频宽带 + 尖叫 | 换轴承/电机 |
| 机臂/起落架共振 | 固定频率，落地敲击可复现 | 加筋、改截面、加阻尼 |
| 气流与下洗 | 低频随机 | 减桨盘载荷、改布局 |
| 线缆/电池松动 | 冲击式尖峰 | 固定、加缓冲 |

**桨叶通过频率（BPF）**：

```
BPF = RPM / 60 × 叶片数
```

例：28 寸两叶桨，悬停转速约 2600 RPM → BPF ≈ 87 Hz，二谐波 174 Hz。陷波中心频率应设在这里。

## 2. 判据：先看数据再动手

| 指标 | 正常 | 异常 |
| --- | --- | --- |
| `VIBE.VibeX/Y/Z` | < 30 m/s² | 持续 > 30 关注，> 60 必须处理 |
| `IMU.AccX/Y/Z` | 无削顶（±16g 量程不触顶） | 出现平顶波形 = 振动已失真 |
| 陀螺频谱 | 主峰明确、幅值低 | 多峰、宽带抬升 |

## 3. 滤波链（从传感器到电机）

```
IMU 采样 → INS_GYRO_FILTER（低通） → 陷波(INS_HNTCH) → ATC_RAT_*_FLTD/FLTT → PID
```

| 参数 | 作用 | 调整方向 |
| --- | --- | --- |
| `INS_GYRO_FILTER` | 陀螺低通截止（Hz） | 桨大转速低→降低；抖动仍大→再降，但会加相位滞后 |
| `INS_ACCEL_FILTER` | 加速度计低通 | 一般保持默认 |
| `INS_HNTCH_ENABLE` | 陷波总开关 | 有明确窄带峰时开 |
| `INS_HNTCH_FREQ` | 中心频率 | 设为 BPF 或实测峰值 |
| `INS_HNTCH_BW` | 带宽（Hz） | 覆盖峰值宽度的一半左右，过宽会吃掉有用信号 |
| `INS_HNTCH_ATT` | 衰减深度（dB） | 一般 30–40 |
| `INS_HNTCH_HMNCS` | 谐波数量（位掩码） | 2 叶桨常开 2–3 次谐波 |
| `INS_HNTCH_MODE` | 频率跟踪方式 | 固定 / 随油门 / 随电调转速 |
| `INS_HNTCH_REF` | 参考量（油门或转速） | 与 MODE 配套 |
| `INS_LOG_BAT_MASK` | 记录批处理 IMU 数据供 FFT | 调振动时开 |
| `FFT_ENABLE` | 机载 FFT | 支持时开启，自动识别主峰 |

## 4. 两种调法

**A. 手工陷波（稳、可控）**
1. 开 `INS_LOG_BAT_MASK` 飞一段悬停；
2. 用地面站 FFT 工具看峰值频率；
3. 设 `INS_HNTCH_FREQ` = 主峰，`BW` 覆盖峰宽，`HMNCS` 开谐波；
4. 复飞对比频谱与振动值。

**B. 自动 FFT（省事）**
1. 开 `FFT_ENABLE`，设 `FFT_MINHZ`/`FFT_MAXHZ` 限定搜索范围；
2. 飞行中自动识别主峰并驱动陷波；
3. 仍需复查 `VIBE`，自动识别也有误判。

## 5. 顺序不能颠倒

1. 机械：桨平衡、紧固、线缆、机臂刚度；
2. 传感器：减震垫软硬是否合适（太软会引入低频摆动）；
3. 滤波：低通 + 陷波；
4. 最后才是 PID。

先调 PID 再治振动，等于用增益去追一个机械问题，越追越糟。

## 6. 常见陷阱

- **陷波过宽**：把有用的控制信号一起衰减，表现为「反应变慢、发飘」。
- **低通过低**：相位滞后增大，D 项失效，反而更容易振荡。
- **只看 VIBE 不看频谱**：VIBE 是加权值，看不出是哪个频率在闹。
- **减震垫越软越好**：错。太软会让 IMU 相对机体晃动，产生低频假信号。
- **换桨不重标定**：桨重变化会改变悬停油门与 BPF，陷波频率要跟着改。
