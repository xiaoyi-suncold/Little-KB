# 学习渠道索引（含能力边界）

> 记录哪些渠道我能直接读、哪些只能靠你转述，避免以后重复踩坑。

## 1. 我能直接学的

| 渠道 | 形式 | 用法 |
| --- | --- | --- |
| PX4 / ArduPilot 官方文档 | HTML / Markdown | 直接抓正文，参数与流程最可靠 |
| CUAV 雷迅、Holybro、Livox、RoboSense、Hesai、北醒官网 | HTML / PDF | 硬件接口、标定、同步方式 |
| GitHub / Gitee 项目 | README / 源码 / issue | 看 BOM、接线图、驱动、测试脚本 |
| 厂商 SDK 文档 | Markdown | 驱动参数、坐标系、时间戳 |
| 学术论文 / 白皮书 | PDF | 算法原理（FAST-LIO、TECS、EKF） |

## 2. 我学不了的（需要你帮忙）

| 渠道 | 原因 | 替代方案 |
| --- | --- | --- |
| B 站 / 抖音视频 | 无法解析视频画面与语音 | 你把关键结论、参数截图或时间点发我，我入库 |
| 大疆云学堂 | 需要登录/企业账号 | 用 DJI 开发者文档、行业方案页、Terra 文档替代 |
| 直播、闭门培训 | 无法访问 | 事后整理成笔记给我 |

这不是推脱：视频里的**现象描述**（怎么抖、怎么响、怎么炸）往往比文档更有价值，你转述三句话，我就能对上诊断树。

## 3. 视频平台的检索与筛选

关键词（按目的分）：

| 目的 | 关键词 |
| --- | --- |
| 调参 | `ArduPilot调参`、`六轴无人机PID整定`、`PX4装机调试` |
| 故障 | `无人机炸机复盘`、`无人机抖动分析`、`GPS丢星` |
| 装配 | `无人机布线`、`电机焊接`、`减震安装`、`重心校准` |
| 测试 | `出厂测试流程`、`拉力测试`、`悬停测试` |

筛选标准（满足两条以上才值得看）：

1. 说了机型、固件版本、起飞重量；
2. 给了参数前后对比或日志截图；
3. 说清了失败样本，不只是成功演示；
4. 不是纯带货。

## 4. GitHub / Gitee 怎么找

- 搜 `ardupilot`、`px4`、`uav`、`drone`、`sprayer`、`dronecan`；
- 看 **README 的硬件清单**、`docs/` 里的接线图、`params/` 里的参数文件；
- 看 **issue** 里的真实故障，比教程更接近现场；
- 优先选有 CI、有测试、最近一年有提交的项目。

## 5. 厂商 wiki 的用法

| 厂商 | 重点看什么 |
| --- | --- |
| CUAV | 电源模块标定、传感器校准、调参指引 |
| Holybro | 飞控接线、电调协议、机架参数 |
| Livox | 时间同步、SDK、点云格式 |
| RoboSense / Hesai | 接口协议、PPS/GPRMC、驱动 |
| 北醒（Benewake） | 测距仪量程、接口、避障配置 |

## 6. 内容可信度分级

| 级别 | 特征 | 采信方式 |
| --- | --- | --- |
| A | 官方文档、源码、数据手册 | 直接引用 |
| B | 有数据/日志的工程博客、论坛长帖 | 交叉验证后引用 |
| C | 短视频、口播经验 | 只作线索，必须验证 |
| D | 带货、无参数的"秘籍" | 不采信 |
