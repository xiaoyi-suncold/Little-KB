# 姿态控制原理（串级 PID）

> 目标：看懂 `ATC_*` 每个参数在回路里的位置，知道改它会发生什么，而不是背数值。

## 1. 两条串联的环

```
期望姿态角 ──►[角度环 P]──► 期望角速度 ──►[角速度环 PID]──► 力矩 ──► 混控 ──► 电机
     ▲                    ▲                      ▲
     │                    │                      │
  遥控/飞控            陀螺仪(IMU)            陀螺仪(IMU)
```

- **角度环**（外环，`ATC_ANG_*`）：输入是角度误差，输出是期望角速度。它决定「打杆后机身多快转到目标角度」。
- **角速度环**（内环，`ATC_RAT_*`）：输入是角速度误差，输出是力矩指令。它决定「机身转得多干脆、会不会抖」。

物理约束：`τ = I · α`。同样力矩下，转动惯量越大角加速度越小，所以**大机型的内环增益天然要更低**，这不是调参风格问题，是物理。

## 2. 角度环参数

| 参数 | 作用 | 调大的后果 |
| --- | --- | --- |
| `ATC_ANG_RLL_P` / `ATC_ANG_PIT_P` | 角度误差 → 期望角速度 | 跟手更快，过大则超调、来回摆 |
| `ATC_ANG_YAW_P` | 航向误差 → 期望偏航角速度 | 航向跟手，过大在长机臂上易摆 |
| `ATC_ANGLE_MAX`（旧名 `ANGLE_MAX`） | 全模式最大倾角 | 机动更猛，但位置环/避障更难收敛，抗风余量下降 |
| `ATC_ACCEL_R/P_MAX` | 角加速度上限 | 限制猛打杆时的加速度，防过冲 |
| `ATC_ANGLE_BOOST` | 大角度时放大角速度环 P | 补偿大角度下响应衰减 |

## 3. 角速度环参数

| 参数 | 作用 | 何时动它 |
| --- | --- | --- |
| `ATC_RAT_RLL_P` | 角速度误差 → 力矩（主增益） | 响应迟钝加、高频抖减 |
| `ATC_RAT_RLL_I` | 消除稳态误差（持续侧风、重心偏） | 松杆缓慢漂移时加 |
| `ATC_RAT_RLL_D` | 抑制角速度突变，提供阻尼 | 到位后回摆时加；高频抖时减 |
| `ATC_RAT_RLL_FF` | 前馈：直接用期望角速度预测输出 | 提高跟手性，不增加反馈振荡风险 |
| `ATC_RAT_RLL_IMAX` | 积分上限 | 防积分饱和导致的大幅回摆 |
| `ATC_RAT_RLL_FLTD` | D 项低通（Hz） | D 噪声大时降低 |
| `ATC_RAT_RLL_FLTT` | 目标值低通（Hz） | 杆量太"冲"时降低 |
| `ATC_RAT_RLL_FLTE` | 误差低通（Hz，0=关） | 一般不动 |
| `ATC_RATE_R_MAX` | 角速度环输出上限（%） | **0=不限**；非 0 会削顶修正能力 |

## 4. 输入整形

`ATC_INPUT_TC` 给摇杆指令加一阶平滑：值越大越柔，越小越"跟手但冲"。它不改变稳定性，只改变手感与电机电流冲击。

## 5. 调参的正确顺序（内环优先）

1. **机械与滤波**：桨平衡、机臂刚度、`INS_GYRO_FILTER`、陷波。振动没解决，PID 只是把噪声放大。
2. **角速度环 P**：从保守值起，加到出现高频振荡前一步。
3. **D**：在 P 稳定后加，抑制过冲；出现高频毛刺就退回并降 `FLTD`。
4. **I**：最后加，消除稳态误差；过大会低频慢摆。
5. **角度环 P**：让杆量跟手，不追求极限。
6. **前馈 FF**：想更跟手又不愿加反馈增益时用。

每次只改一个、±10~20%，用同一套动作复飞对比。

## 6. 判据（怎么叫调好了）

- 3 秒满杆回中：超调 ≤ 20%，2 秒内稳定；
- `RATE.*` 无持续等幅振荡，过零 ≤ 2 次；
- `RCOU`（电机输出）不长期贴顶或贴底；
- 悬停 60 秒 `VIBE` 均值低、无削顶；
- 手感：小杆量线性、无死区、无「一碰就过」。

## 7. 三个常见误区

1. **用外环救内环**：角速度环在抖，去加角度环 P 只会更抖。
2. **把限幅当增益**：`ATC_RATE_*_MAX` 非 0 时输出被削顶，表现为「迟钝」，此时加 P 无效。
3. **忽略混控与动力**：电机不同步、桨距差、电调行程不一致，会表现成「某一侧总是慢半拍」，调 PID 无解。
