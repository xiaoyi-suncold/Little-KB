# 飞控生态对比：ArduPilot / PX4 / Betaflight

> 选飞控不是选「哪个更好」，是选「哪套约束更适合你的团队」。

## 1. 定位差异

| | ArduPilot | PX4 | Betaflight |
| --- | --- | --- | --- |
| 目标 | 全平台自动驾驶（Copter/Plane/Rover/Sub/Blimp） | 专业级自驾，强 ROS 集成 | 竞速/自由飞多旋翼 |
| 架构 | 单体飞控 + 参数表 + 模式机 | 模块化 + uORB 消息总线 | 极简单线程，固定周期 |
| 参数 | 扁平大表（1000+），按前缀分组 | 参数系统 + 模块命名空间 | CLI 变量，数量少 |
| 控制 | 位置/速度/加速度/姿态/角速度串级 | 类似分层，命名不同 | 只有角速度环（+ 可选自稳） |
| 生态 | 地面站 Mission Planner / MAVProxy | QGC、ROS2、Gazebo | Betaflight Configurator、Blackbox |
| 典型用户 | 行业作业、科研、长航时 | 研究、集群、视觉导航 | 穿越机、竞速、FPV |

## 2. 控制结构的对应关系

| 层级 | ArduPilot | PX4 | Betaflight |
| --- | --- | --- | --- |
| 角速度 P | `ATC_RAT_RLL_P` | `MC_ROLLRATE_P` | `pids roll P` |
| 角速度 I | `ATC_RAT_RLL_I` | `MC_ROLLRATE_I` | `pids roll I` |
| 角速度 D | `ATC_RAT_RLL_D` | `MC_ROLLRATE_D` | `pids roll D` |
| 前馈 | `ATC_RAT_RLL_FF` | `MC_ROLLRATE_FF` | `feedforward` |
| 角度 P | `ATC_ANG_RLL_P` | `MC_ROLL_P` | 无（自稳模式用 level 参数） |
| 位置 P | `PSC_NE_POS_P` | `MPC_XY_P` | 无 |
| 速度 P | `PSC_NE_VEL_P` | `MPC_XY_VEL_P` | 无 |
| 高度 | `PSC_D_*` | `MPC_Z_*` | 无 |

命名不同，但**内环都是角速度环**。会调一个，另一个只需换名字。

## 3. 调参哲学差异

- **ArduPilot**：参数多、默认保守，强调「按流程走」；自动调参（AUTOTUNE）成熟；位置环与 EKF 耦合深。
- **PX4**：模块化清晰，参数有明确命名空间；适合二次开发（offboard、ROS2）；默认更依赖机型模板。
- **Betaflight**：只有 rate 环，靠 **feedforward + 动态滤波 + RPM 滤波**提升手感；调参靠黑盒与飞行手感，不追求位置控制。

Betaflight 的几条经验对其他平台同样成立：

1. **D 项放大噪声**，必须低通；D 过高会让电机过热。
2. **前馈不引起振荡**，能在不加 P 的前提下提升跟手性。
3. **先降噪再调参**，滤波每加一层就多一份延迟。
4. **振荡分频段**：高频抖 → 降 D / 查噪声；低频摆 → 升 D 或降 P。

## 4. 日志与工具

| | 格式 | 工具 |
| --- | --- | --- |
| ArduPilot | `.bin` / `.log`（DataFlash） | Mission Planner、MAVExplorer、PlotJuggler |
| PX4 | `.ulg` | Flight Review、PlotJuggler、QGC |
| Betaflight | Blackbox | Blackbox Explorer、PID Toolbox |

## 5. 怎么选

| 场景 | 建议 |
| --- | --- |
| 行业作业机（植保/清洗/巡检） | ArduPilot：模式全、失效保护成熟、参数可审计 |
| 视觉/集群/科研 | PX4：ROS2 生态与 offboard 接口更顺 |
| 穿越机/竞速 | Betaflight：延迟最低、生态最全 |
| 需要适航/可追溯 | ArduPilot 或 PX4：参数与日志可导出、版本可锁定 |

## 6. 迁移注意

- 参数名不同，**不要按数值照搬**：同样的角速度环 P，量纲与归一化方式不同。
- 模式语义不同：ArduPilot 的 Loiter ≈ PX4 的 Position；Betaflight 没有位置环。
- 故障保护逻辑不同：PX4 的 failsafe 在 commander 模块，ArduPilot 在 `FS_*` 参数。
- 日志字段不同，分析脚本不能复用。
