# 飞行模式与失效保护

> 失效保护不是「打开一个开关」，而是一组**互斥、可验证、有人接管**的策略。

## 1. 模式速查

| 模式 | 控制什么 | 典型用途 | 依赖 |
| --- | --- | --- | --- |
| Stabilize | 姿态角 | 手动基础飞行 | 姿态估计 |
| Acro | 角速度 | 特技/穿越 | 姿态估计 |
| AltHold | 高度 + 姿态 | 手动作业 | 气压/测距 |
| Loiter | 位置 + 高度 + 航向 | 定点作业 | GPS/EKF |
| PosHold | 位置（杆量映射速度） | 手感接近手动 | GPS/EKF |
| Auto | 任务 | 航线作业 | GPS + 任务 |
| Guided | 地面站指令 | 指点飞行 | GPS |
| RTL | 返航 | 失联/手动触发 | GPS + 航向 |
| SmartRTL | 沿来路返回 | GPS 变差时 | 路径记录 |
| Land | 原地降落 | 低电量/故障 | 高度源 |
| Brake | 急停悬停 | 紧急 | 位置估计 |
| Circle / Follow / ZigZag | 环绕/跟随/之字 | 测绘/巡检 | GPS |

模式分配：`FLTMODE1..6` 对应遥控开关档位，`FLTMODE_CH` 指定通道。

## 2. 失效保护矩阵（按风险排序）

| 失效 | 参数 | 动作选项 | 工程建议 |
| --- | --- | --- | --- |
| 遥控失联 | `FS_THR_ENABLE` | RTL / Continue / Land / SmartRTL | 作业区有障碍时用 RTL，室内用 Land |
| 地面站失联 | `FS_GCS_ENABL` | 同上 | 长航线可设 Continue，但要有超时上限 |
| 低电量 | `BATT_FS_LOW_ACT` | 0=无 / 2=RTL / 3=Land | **不要设 0**，至少 RTL |
| 严重低电量 | `BATT_FS_CRT_ACT` | Land / RTL / 降落伞 | 必须设，且电压阈值要按电芯数算 |
| EKF 异常 | `FS_EKF_ACTION` | Land / RTL / SmartRTL / Brake | 室内 Land，室外 RTL，强风 Brake |
| 围栏越界 | `FENCE_ACTION` | RTL / Land / 仅报告 | 与 `FENCE_TYPE` 配套 |
| 降落伞 | `CHUTE_*` | 手动/自动触发 | 只在大机型上，需独立电源 |

## 3. 围栏

| 参数 | 含义 |
| --- | --- |
| `FENCE_ENABLE` | 总开关（**很多人只设了半径没开这个**） |
| `FENCE_TYPE` | 位掩码：1=最大半径 2=多边形 4=最大高度 8=最小高度 |
| `FENCE_RADIUS` | 半径（m） |
| `FENCE_ALT_MAX` / `MIN` | 高度上下限（m） |
| `FENCE_ACTION` | 越界动作 |
| `FENCE_AUTOENABLE` | 解锁/任务自动启用 |

验证方法：把半径设小，手动飞出测试是否触发——**没测过的围栏等于没有**。

## 4. 解锁检查

| 名字 | 说明 |
| --- | --- |
| `ARMING_CHECK`（≤4.7） | 位掩码：启用哪些检查，1=全部 |
| `ARMING_SKIPCHK`（4.8+） | 位掩码：**跳过**哪些检查，默认 0 |

常见位：气压计、罗盘、GPS、INS、参数、RC、板电压、电池、日志、开关、GPS 配置、系统、任务、测距、视觉、FFT。

**跳过 INS 或参数检查是危险操作**：INS 检查能拦住「未校准/安装方向错」，参数检查能拦住「参数版本不匹配」。除非现场排障，不建议长期关。

## 5. 设计原则

1. **可达**：失效时飞机能到的地方，必须是安全的地方（空旷、无人）。
2. **可验证**：每个保护都要设计一次触发测试，记录在案。
3. **不互斥**：低电量 RTL 与围栏 RTL 不能打架（例如围栏半径小于返航所需距离）。
4. **有人接管**：任何自动策略都要留遥控接管通道，且接管优先。
5. **失效降级**：GPS 没了退到 AltHold/Stabilize，而不是直接掉。

## 6. 常见错误

- 只设 `FENCE_RADIUS` 不设 `FENCE_ENABLE`；
- 低电量动作设为「无」，靠飞手看电压；
- 解锁检查被大面积跳过，起飞后才发现罗盘没校准；
- EKF 失效设成 RTL，但 GPS 本身就不可信；
- 降落伞触发高度高于实际作业高度，永远用不上。
