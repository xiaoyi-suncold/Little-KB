# 系留无人机组装与调试（从零到 300 m 悬停的工程流程）

> 系留不是"给无人机拴根电线"。它是一套**地面供电 + 高压输电 + 自动收放 + 机载电源 + 失效保护**的耦合系统，组装和调试的重点全在"电与线"上，机架只是载体。
> 本文为设计/流程整理，未做整机实测的段落已标注"设计"。

## 结论

1. **系留的核心是功率预算**：先算悬停功率 → 定系缆电压（现主流 400–800 V DC）→ 定导体截面 → 反推系缆重量 → 校验推重比与可用高度。链条任一环超了，整机飞不起来。
2. **组装的关键工序只有四步**：机架/动力按普通多旋翼做（对桨、扭矩、转向）→ 系缆走机腹承力点且不承机身载荷 → 机载电源模块独立固定+单独散热 → 加装备用电池做"断缆返航"。
3. **调试的关键不是 PID，是失效注入**：低空 5 m 悬停 → 逐级升到 50/100/300 m → 拉线缆张力/缠绕测试 → 拔地面电、模拟断缆、模拟发电机停机，看是否 5 s 内进入返航、机载电池是否够降落 2.5 min 以上。
4. 商用参考量级：800 V 系缆机型功耗 8–10 kW、连续工作 400 h+，机载端把 800 V 降到 50 V；机载电源模块常见 ≤460 g、输出 DC 50 V±1 V、连续 ≥24 h（招标/产品参数口径）。
5. 系缆轻量化的行业量级：光电复合缆 **100 m ≈ 1.5 kg**（10 A、耐压 3000 V）、抗拉 50–100 kg、内含单模光纤。

## 机制：为什么必须高压、必须恒张力

**功率传输**
- 同功率下电压越高电流越小：`I = P / V`，线路损耗 `P_loss = I²R = P²R / V²`。电压翻倍，线损降到 1/4。
- 线损小了，导体就能做细；导体细了，系缆就轻；系缆轻了，同一台机才能飞更高或挂更重。这就是为什么系留机都在往 800 V 甚至更高电压走。
- 代价是绝缘、爬电距离、连接器、EMI 都变难，机载端必须有高效率固定比率变换器（BCM 类，98% 量级）在顶部降压。

**系缆的力学**
- 系缆有三重身份：输电通道、通信通道（光纤）、**受力构件**（拉力由凯夫拉/超高分子量聚乙烯承担，铜只导电）。
- 悬停时系缆给无人机一个向下的拉力分量 + 水平风阻；高度越高、线越重、风越大，这个分量越大，需要预留推力余量。
- 绞车的作用是把拉力控制在"不拖地、不拽机"的窄窗口里——**恒张力优先于恒长度**：长度模式会在大风下把机拽偏，张力模式才有余度。

**电力链路（典型拓扑）**
市电/发电机 → 整流升压（400–800 V DC）→ 绞车滑环 → 系缆 → 机腹接插件 → 机载高压变换器（→ 48/50 V）→ 分电板/ESC → 电机；同时一路给飞控、图传、载荷。
备用电池与主电之间是非对称冗余：正常时被充电/旁路，主机失电时接管，**切换时间要小于飞控的失控判定时间**。

## 实现：功率预算与选型（设计，带算例）

### 1. 悬停功率
经验区间：多旋翼悬停功率约 **80–150 W/kg**（起飞重量口径，大轴距高效率端，小机器偏高；经验值，需以厂家拉力-功率表核对）。
算例：起飞重量 10 kg 的系留机，取 120 W/kg → 悬停约 1.2 kW；加机载设备/载荷余量 30% → 地面端按 **1.6 kW 连续**设计，峰值按 2 倍留。

### 2. 系缆电压与压降
要求：满功率时末端压降 ≤ 5~8%，机载端输入不低于变换器最低工作电压。
```
铜电阻率 ρ ≈ 0.0175 Ω·mm²/m
R_total = 2·ρ·L / A          # 双导体，L 为系缆长度(m)，A 为单根截面(mm²)
ΔU = I·R_total   ;  P_loss = I²·R_total
```
算例：L = 100 m、A = 0.75 mm² → R = 2×0.0175×100/0.75 ≈ **4.67 Ω**。
- 400 V 传 4 kW（I = 10 A）：ΔU ≈ 47 V（12%）、线损 467 W —— 勉强但浪费。
- 800 V 传 4 kW（I = 5 A）：ΔU ≈ 23 V（3%）、线损 117 W —— 可用。
结论：**长缆、大功率必须上高压**；400 V 只适合短缆小功率。

### 3. 系缆选型要点
| 参数 | 关注点 |
| --- | --- |
| 导体 | 轻型合金/铜包铝，截面按电流密度 4–6 A/mm² 长线降一档 |
| 抗拉 | 凯夫拉/UHMWPE 承力，破断力 ≥ 工作拉力 ×5 |
| 耐压 | 长期工作电压留 3 倍以上余量（3000 V 缆跑 800 V 很常见） |
| 重量 | 100 m ≤1.5–3 kg；重量直接吃掉载荷与高度 |
| 通信 | 单模光纤（抗干扰、可传高清），或屏蔽双绞备用 |
| 护套 | 聚氨酯/尼龙，耐反复弯曲、耐磨、防紫外 |

### 4. 绞车与收放
- 排线机构（往复丝杆 + 导向轮）保证收线整齐不打结，这是最容易忽视的机械点。
- 张力传感 + 编码器双反馈；控制律：张力环外、速度环内；收放速度约 1 m/s 量级。
- 必备：手动收线/应急释放、限位、断线检测、滑环（旋转不绞线）。

## 组装流程（8 步，按顺序做）

1. **环境与合规前置**：电源容量（≥地面端功率 ×1.5）、接地与漏保、空域/报备、风速（≥6 级不飞）、地面硬化与警戒区。
2. **机架与动力**：按普通多旋翼装配；正反桨与电机一一对应，H 型高压电机螺丝按厂家扭矩（振动大的位置加螺纹胶）；碳管无分层、折叠件无旷量。
3. **无桨通电**：检查电机转向、顺序、响应；飞控自检无告警。
4. **机载电源模块安装**：独立减震+独立风道，远离罗盘/GPS（高压变换器 EMI 大）；输入接插件朝下做滴水弯；固定螺丝加胶。
5. **系缆与承力路径**：系缆拉力由机腹专用承力点/吊环承担，**不允许电缆直接受力于接插件**；预留 20–30 cm 应力释放弯；接插件锁死并做二次防脱（保险丝/扎带）。
6. **绞车与滑环对接**：手动收放 3 个来回，确认排线整齐、无异响、限位有效；空载张力零点标定。
7. **备用电池**：容量满足"断缆后降落 ≥2.5 min"（标准口径，见下），安装位置不破坏重心；BMS 与飞控电压监测连通。
8. **载荷与重心**：装相机/照明/基站后做重心校准（吊点法，前后左右偏差 ≤5% 轴距），再复称总重并回填功率预算。

## 调试流程（分 5 个阶段，每阶段留记录）

### 阶段 1：地面联调（不飞）
- 地面站连飞控：限高、限速、返航高度、失控保护（RC 丢失/数传丢失/低电）逐项设好。
- 罗盘、加速度计、水平校准；GPS/RTK 固定解。
- 电力链路空载/假负载测：地面端输出电压、机载端输入电压、各节点温升（满载 10 min，壳体温度不超厂家限值）。
- 张力标定：挂砝码标定张力传感器读数，误差 ≤3%。

### 阶段 2：系缆静态拉拽
- 地面通电、机不飞，绞车以 1 m/s 收放，观察张力曲线是否平滑、有无跳变（跳变=排线卡滞或滑环问题）。
- 模拟断缆：人为断开机载输入，测切换时间与飞控告警。

### 阶段 3：低空悬停（≤5 m）
- 悬停 3–5 min：看电机温度、系缆姿态（有无打圈/擦地）、姿态是否稳、电流是否与预算吻合。
- 记录磁罗盘是否被系缆电流干扰（大电流时航向漂移 = EMI 问题，改线或加屏蔽/磁屏蔽）。

### 阶段 4：逐级升限（**每级先悬停稳定再升**）
50 m → 100 m → 目标高度（商用常见 100–300 m）。
每级检查：
- 绞车张力是否自动跟随（张力恒定、不拖地、不拽机）；
- 风速增大时姿态与位置保持（大风下会出现"被线拖着走"的偏航/漂移，需要前馈或放宽位置环）；
- 图传/光纤链路误码、延迟；
- 电池 SOC 是否在旁路状态维持（备用电池不应长期放电）。

### 阶段 5：耐久与故障注入
- 低载荷 8 h 耐久（24 h 场景做满）；每 2 h 记录温度、电压、张力、振动。
- 故障注入清单：
| 注入 | 期望动作 |
| --- | --- |
| 拔地面主电 | 5 s 内触发强制返航，机载电池接管，能降 ≥2.5 min |
| 系缆断线/脱线 | 同上，且绞车停转、报警 |
| 发电机停机/市电断 | 报警 + 自动降落/返航 |
| 遥控丢失 | 按飞控 Failsafe 返航 |
| 绞车卡死/张力超限 | 张力上限保护，飞控收到告警 |
| 单电机失效 | 多旋翼视余度而定：至少保持可控降落 |

## 飞控与参数调试要点

- **限高/限远**必须小于系缆长度（留 10–20% 余量），否则拉断缆。
- **返航策略**：系留机不要用"直线返航到起飞点"，改**原地降落或沿缆收线下降**，避免绕线。
- **位置环放宽**：系缆拉扯会引起位置误差，位置环 P 太大就振荡；一般先保证姿态环稳定，再适度降低位置增益、增大速度环阻尼。
- **定高**：系留机在风里会被线拽成小幅俯仰摆动，定高加一点死区/滤波更稳。
- **电流/抗扰**：高压变换器开关噪声会污染 IMU/罗盘，实测常见做法是加屏蔽、加磁屏蔽罩、错开采样时刻；若航向漂移随负载变化，先怀疑 EMI。
- **张力前馈（进阶）**：把张力传感器读数接进自驾仪做前馈，可显著改善大风下的位置保持；无此接口时用"限位 + 收线跟随"降级方案。

## 边界与失败模式

| 症状 | 可能原因 | 处置 |
| --- | --- | --- |
| 升到 100 m 后电流暴涨、掉高 | 线损按短缆算、机载端输入跌到欠压 | 换高压/加截面，重算压降 |
| 悬停时机身被横拽、漂移 | 绞车处于长度模式或张力过大 | 切恒张力、降低收线速度 |
| 大电流时航向漂移 | 系缆磁场干扰罗盘 | 移远罗盘、磁屏蔽、双罗盘一致性检查 |
| 收线打结 | 排线机构失效/导向轮间隙大 | 停机手收，检查往复丝杆 |
| 断缆后直接自由落体 | 备用电池不在位/切换失败 | 检查切换电路、电池 SOC，做断缆注入测试 |
| 机载模块过热降额 | 无风道、贴着机身 | 独立风道、散热片、限功率 |
| 雨雾天绝缘报警 | 接插件进水、护套破损 | 滴水弯、防水接头、定期绝缘电阻测试 |

安全红线：雷雨不飞（系缆即引雷天线）、人群上方不飞（缆绳缠绕/绊倒风险）、机身/绞车设警戒区、高压侧带电不得徒手检查、断电后电容需放电。
