# 设计流程与校核（新机型）

> 从「要做什么」到「能量产」，八个阶段，每阶段有交付物和通过判据。跳阶段是返工的主要原因。

## 阶段 0 · 需求定义

先把需求写成可计算的指标，而不是形容词。

| 维度 | 要问的问题 | 输出 |
| --- | --- | --- |
| 任务 | 喷洒/清洗/巡检/测绘/物流？ | 作业模式与载荷类型 |
| 载荷 | 多少 kg？体积？供电？ | 载荷包络与接口 |
| 续航 | 单架次时间/面积 | 能量预算 |
| 环境 | 温度、海拔、风速、防护等级 | 动力与防护设计输入 |
| 起降 | 场地尺寸、是否船上/车上 | 尺寸与起落架 |
| 运输 | 是否折叠、装箱尺寸 | 结构方案 |
| 法规 | 最大起飞重量、空域、实名 | 合规约束 |
| 成本 | 目标 BOM 与售价 | 选型边界 |

**通过判据**：一张「需求→指标」表，每个指标都有数值和容差。

## 阶段 1 · 构型选择

| 构型 | 优势 | 劣势 | 适用 |
| --- | --- | --- | --- |
| 四轴 | 结构简单、效率高、成本低 | 单发失效不可控 | ≤25 kg 常规作业 |
| 六轴 | 冗余、载重强、抗风好 | 重量与成本上升 | 25–50 kg 作业 |
| 八轴 | 更高冗余 | 更重、更贵 | 高价值载荷 |
| 共轴双桨 | 体积小、推力密度高 | 效率低、控制耦合 | 紧凑型 |
| 复合翼 | 航程远 | 结构复杂、悬停效率低 | 长航时测绘 |

**通过判据**：构型与任务匹配，且有明确的失效策略（单发失效如何处理）。

## 阶段 2 · 动力选型

按 [动力系统匹配](动力系统匹配.md) 的七步走：起飞重量 → 桨径 → 桨盘载荷 → 电机 KV → 拉力表 → 电调 → 电池。

**通过判据**：T/W 1.6–2.2、W/A 25–60 kg/m²、悬停油门 0.25–0.45、单轴电流 ≤ 电调持续电流/1.3。

## 阶段 3 · 结构与布局

- 轴距与桨径满足桨尖间隙 ≥5%；
- 机臂一阶频率 > 2×BPF（见 [结构设计与共振](结构设计与共振.md)）；
- 重心在几何中心 ±5%，满载/空载偏移可控；
- 折叠机构、起落架、载荷挂点有明确刚度方案。

**通过判据**：敲击测试无低频共振峰落在工作转速范围。

## 阶段 4 · 电气与电源

- 电池 S 数、容量、C 数满足能量与峰值电流；
- 分电、线径、连接器、保险按峰值电流设计；
- 电源模块标定方案（模拟需标定，CAN 出厂校准）；
- 信号地与功率地分离，罗盘远离大电流回路。

**通过判据**：地面满载测试压降 <5%，线束与连接器温升可接受。

## 阶段 5 · 飞控与参数

1. 固件版本锁定（记录 ArduPilot 版本号，参数名随版本变）；
2. 传感器标定（见 [传感器与标定](传感器与标定.md)）；
3. 混控与电机顺序核对；
4. 滤波与陷波（见 [振动滤波与陷波](振动滤波与陷波.md)）；
5. PID 整定（见 [姿态控制原理](姿态控制原理.md)）；
6. 失效保护与围栏（见 [飞行模式与失效保护](飞行模式与失效保护.md)）。

**通过判据**：每个保护都做过一次触发测试，参数文件纳入版本管理。

## 阶段 6 · 地面试验

| 试验 | 方法 | 判据 |
| --- | --- | --- |
| 单电机转向/顺序 | 低油门逐个点动 | 与混控表一致 |
| 拉力测试 | 系留测力 | 达到设计拉力 ±5% |
| 共振扫描 | 逐级油门 | 工作区间无结构峰 |
| 振动基线 | 悬停前的地面旋转 | `VIBE` 在阈值内 |
| 电源满载 | 假负载/系留 | 压降与温升合格 |
| 失效注入 | 拔遥控/关地面站 | 保护动作正确 |

## 阶段 7 · 试飞

1. 悬停 60 秒（看振动、电流、温度）；
2. 定点 5 分钟（看漂移、画圈）；
3. 航线作业（看速度、覆盖、返航）；
4. 极限：最大载重、最大风、最低电量返航；
5. 每次飞行后导出日志，与基线对比。

**通过判据**：所有指标在容差内，且异常有解释（不能「飞着没事」就算过）。

## 阶段 8 · 迭代与量产

- 参数与结构版本化（每次改动可回滚）；
- BOM 与工艺文件；
- 出厂测试项（标定、拉力、振动、保护触发）；
- 维护周期（桨、电机轴承、电池、密封件）。

## 风险登记（常见）

| 风险 | 触发条件 | 缓解 |
| --- | --- | --- |
| 推重比不足 | 载重估算偏乐观 | 按满载 +10% 校核 |
| 结构共振 | 折叠件/长悬臂 | 敲击测试 + 加筋 |
| 电压平台不自洽 | 改电池未改阈值 | 参数自检清单 |
| 罗盘干扰 | 高压大电流 | 双罗盘/移动基线 |
| 水雾/腐蚀 | 清洗场景 | IP 等级 + 材质 |
| 单点失效 | 单 GPS/单 IMU | 冗余与降级策略 |
| 法规超限 | 超重/超空域 | 设计阶段就锁定 |
