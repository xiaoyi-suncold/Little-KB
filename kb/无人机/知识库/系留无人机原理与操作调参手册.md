## 一、原理：三条链

### 1. 能量链（为什么高压）
`I = P/V`，`P_loss = I²R = P²R/V²`。电压翻倍线损降到 1/4，导体可细一半，系缆轻了才飞得高、挂得动。
- 地面端：市电/发电机 → 整流升压 → 400–800 V DC（Vicor 案例：800 V 上缆，机载降 50 V，8–10 kW，连续 400 h+）。
- 机载端：高效率固定比率变换器（BCM 类，98% 量级）降压，加一路给航电/载荷。
- 缓冲：机载电池做浪涌缓冲与断缆备份，不是主能源。理想二极管/限流 DC-DC 让"缆供+电池"平滑切换。

### 2. 力学链（缆是受力件）
- 系缆 = 输电线 + 光纤 + 承力纤维（凯夫拉/UHMWPE）。破断力按工作拉力 ×5 起。
- 空中形态是**悬链线**：缆自重让中段下垂，风让它侧弯。缆给机的力 = 向下的重量分量 + 水平阻力，两者都随高度、风速、缆长增大。
- 因此：可用高度被"缆重+风阻+推力余量"三重夹住，商用实用区间 100–300 m；单套照明机型常见 30–100 m。
- 绞车控制律：外环张力、内环速度。**恒张力优于恒长度**——长度模式在大风下会把机拽偏，甚至拉成"风筝"。学术侧（arXiv 2412.09502）用 backstepping 统一机-绞车模型，稳定目标是让缆保持悬链形态、按期望长度跟踪。

### 3. 控制链（缆引入的扰动）
缆对飞控是**一个随高度/风速变化的未知外力**，表现为：
- 俯仰/横滚的持续偏置力矩（顺风时被往前拽，逆风被往后拉）；
- 位置环的稳态误差（想定住就会被缆拉走一点）；
- 张力突变时的抖动（绞车收放不同步、阵风）。
公开专利思路（CN113885545B）：**先算缆绳张力，再把张力作为前馈补偿进控制律**，减小"张力造成的未知干扰"，提高定点精度。工程降级方案：张力上限保护 + 收线跟随 + 放宽位置环。

## 二、操作方案（日常作业 SOP）

### 1. 飞行前
| 项 | 检查 |
| --- | --- |
| 场地 | 硬化平整、远离人群/道路，机身与绞车划警戒区（缆绳会绊人、会缠人） |
| 电源 | 市电容量 ≥地面端功率×1.5；或发电机油量够整班次；接地+漏保 |
| 风 | 一般 ≤6 级（厂家常用口径；大风机型另定），阵风突变不飞 |
| 天气 | 不打雷（系缆等于引雷天线）、不下雨（高压接头怕水）、能见度够 |
| 系缆 | 护套无破损、接头锁死、绝缘电阻合格、排线整齐 |
| 空域 | 报告/报备，作业高度与限高一致，缆长留 10–20% 余量 |
| 电池 | 机载备份电池满电（断缆后降落 ≥2.5 min，T/CECS 5.3.2 已核实） |
| 地面箱 | 显示电压按机型核（如 500 V±1 V）、电流 0—0.5 A；红灯常亮=立即降落 |
| 线缆 | 不打结、不受压；拖出线缆前先开收放线开关，避免箱内松弛 |
| 人员 | 飞手 + 绞车/地面电源操作员分工，应急口令与手动收线流程演练过 |

### 2. 起飞与升降
1. 地面端先上电、机载端自检（电压/电流/温度正常）→ 再解锁。
2. 起飞用**垂直爬升**，绞车同步放线（跟随高度），保持缆微松不拖地。
3. 到位后切定高/定点，观察 1–2 min：张力稳定、姿态无持续偏置。
4. 起飞后先在 **2 m 高度停 2 min**，无异常再缓慢升空；失控保护设**降落**，不设失控返航；作业半径 **20 m** 内清场（无人机下方及周边不得有人、车、贵重物）。
5. 上电顺序：地面供电 → 机上航空插头 → 飞控 → 电池（禁止带电插拔高压）；400 V 级产品操作戴绝缘手套。
6. 降落时先降高度再收线，**不要让绞车先拉**；落地后断机载电源再断地面端。

### 3. 长时值守（12–24 h）
- 每 1–2 h 记录：地面端输出电流/电压、机载端输入电压、缆张力、电机与变换器温度、电池 SOC（备份电池应保持满）。
- 交接班双人复核；换发电机油/换市电要预先切到 UPS 或短时电池供电。
- 天候恶化（阵风、雷暴临近）**提前降落**，不在临界值硬撑。
- 缆绳张力突然变大/变小、收放异响 = 立刻降高检查（排线卡滞、缠线最常见）。

### 4. 应急
| 事件 | 动作 |
| --- | --- |
| 地面断电/发电机停机 | 机载电池接管 → 5 s 内触发强制返航或原地降落（T/CECS 5.3.2，已核实） |
| 系缆断线/脱线 | 同上，绞车立即停转报警，禁止继续拉线 |
| 绞车卡死 | 切手动放线/应急释放，飞行器保持定高，人撤离缆下 |
| 缆缠绕/被勾挂 | 停止收线，降低高度，必要时地面断缆（先断高压、再断机械） |
| 姿态失控 | 优先降高，切手动/自稳，禁止在缆受力状态做大机动 |

## 三、调参方案

### 1. 参数优先级（先安全后性能）
1. **地理围栏/限高**：限高 < 缆长 × 0.8–0.9（ArduPilot `FENCE_*` / PX4 `GF_*`，按机型选）。
2. **失效保护**：RC 丢失、数传丢失、低电、外部供电异常 → 返航/降落；ArduPilot `FS_*`、`BATT_*`，PX4 `COM_*_FAIL`、`NAV_RCL_ACT`。
3. **降落策略**：系留机不要"直线返航到起飞点"（会绕缆），改**原地降落 + 收线跟随**或"沿缆垂直下降"。
4. **姿态环**：普通多旋翼流程调好（先 rate 后 attitude），缆不影响这一层，先保证地基稳。
5. **位置/定高**：缆的持续拉力会造成稳态偏差与低频摆动，位置环 P 一般要比自由飞略降、速度环阻尼略增。
6. **张力前馈（进阶）**：有张力传感器且自驾仪支持外部扰动前馈时接入；无接口则用"限张力 + 收线跟随"。

### 2. 调参顺序（每步只看一个变量）
| 步 | 做什么 | 判据 |
| --- | --- | --- |
| 1 | 无缆自由飞，调 rate/attitude | 阶跃响应无超调振荡，`VIBE`/FFT 在阈值内 |
| 2 | 挂缆不供电，地面拉拽标定张力传感器 | 砝码法误差 ≤3% |
| 3 | 5 m 悬停，记录定点漂移量与电流 | 漂移可预期（顺风被拽），电流接近预算 |
| 4 | 降位置环 P 10–20%，看漂移是否收敛 | 无低频摆动、无"追着跑" |
| 5 | 定高加死区/滤波，测风下高度保持 | 高度波动 < 设定阈值（如 ±1 m@100 m） |
| 6 | 加张力前馈（如可），重测定点精度 | 定点误差明显下降且不引入振荡 |
| 7 | 大风（接近风限 70%）下复测 | 可控、不触保护、不缠线 |

### 3. 常见调参坑
- **限高设太大**：升到缆尽头被硬拉，瞬间大电流+姿态突变。
- **返航高度/返航点设错**：系留机返航时绕缆缠线，比不返航更危险。
- **位置环 P 图定得高**：缆的持续拉力被当成"误差"，越修越偏，形成低频摆动。
- **不看电流只看电压**：缆压降随负载变化，电压看着正常电流已超缆载流。
- **罗盘被缆磁场干扰**：大电流时航向漂移，先做"带载罗盘一致性"测试再谈调参。

## 四、注意事项（工程 + 安全 + 合规）

**电气**
- 高压侧断电后电容仍带电，检修前放电；接头朝下做滴水弯。
- 导体按 4–6 A/mm² 选，长缆降一档；缆破断力 ≥工作拉力 ×5。
- 机载变换器必须独立风道，远离罗盘/GPS（EMI 会污染导航）。

**机械**
- 承力点走机腹吊环，接插件**绝不承力**；预留应力释放弯 + 二次防脱。
- 排线机构（往复丝杆+导向轮）是耐久性最脆弱环节，定期检查。
- 起落架要能吸收"落回地面时缆的残余张力"。

**作业安全**
- 缆绳是隐形危险源：人群、道路、螺旋桨下方都要清场；雷雨天禁飞。
- 双人作业，绞车操作员必须能独立执行"断缆+手动收线"。
- 24 h 作业要有换班与天候熔断机制。

**合规（国内口径，详见 法规与空域要点.md）**
- 系留机属超视距/特定类作业，需实名、报备、按作业类型审批；高度受限高与空域双重约束。
- 消防/应急场景按使用单位的飞行训练规程执行（如消防照明模块飞行训练要求）。

## 六、边界与失败模式

| 现象 | 根因 | 处置 |
| --- | --- | --- |
| 定点漂移、越修越偏 | 位置环把缆拉力当误差 | 降位置环增益，加张力前馈 |
| 高度越高电流越大 | 缆压降随长度增加，末端欠压 | 提高上缆电压/加大截面，重算预算 |
| 顺风被"拖着走" | 缆风阻 + 绞车长度模式 | 切恒张力，收线跟随 |
| 大电流航向漂移 | 缆磁场干扰罗盘 | 移远/屏蔽，带载罗盘一致性测试 |
| 断缆后直接坠落 | 备份电池不在位或切换失败 | 断缆注入测试，检查切换与 SOC |
| 收线打结/卡死 | 排线机构磨损、导向轮间隙 | 定期维护，手动收线预案 |
