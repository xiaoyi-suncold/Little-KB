# 故障案例库（模板与积累方法）

> 这个页面现在只有方法和模板，没有编造的案例。
> 每收到一份真实日志/事故复盘，就按模板补一条，逐步长成真正的案例库。

## 1. 为什么单独建库

参数页回答「这个参数是什么」，故障手册回答「这种现象可能是什么」，**案例库回答「上一次同样现象，最后查出来是什么」**。三者缺一不可。

## 4. 常见失效模式分类（用于归类，不是具体事故）

| 类别 | 典型表现 | 首要证据 |
| --- | --- | --- |
| 动力失效 | 单轴输出异常、掉高、翻转 | `RCOU` 单路异常、电流突变 |
| 能源失效 | 电压骤降、突然掉电 | `BAT.Volt` 曲线、`PM` |
| 链路失效 | 失控、模式切换 | `MODE.Rsn`、RSSI |
| 导航失效 | 位置跳变、画圈、航向漂 | `XKF4` 方差、`GPS` 质量 |
| 结构失效 | 振动突变、姿态失控 | `VIBE` 阶跃、频谱 |
| 软件/参数 | 行为与预期不符 | 参数快照对比 |
| 人为因素 | 起降失误、超载 | 操作记录、载重 |

## 5. 分析方法

1. **时间线优先**：先把事件按时间排好，再看参数；
2. **5 Why**：连续问五次「为什么」，直到落到可验证的机制；
3. **瑞士奶酪模型**：每层防护为什么都没拦住；
4. **对照法**：拿同机型正常架次做基线，看差异而非绝对值。
