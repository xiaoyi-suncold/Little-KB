# 油动与混动系统

> 电动的瓶颈是能量密度，油动的瓶颈是控制带宽。混动是把两者的缺点都带上，但延长了航时。

## 1. 为什么考虑油

| 能源 | 质量能量密度（约） | 说明 |
| --- | --- | --- |
| LiPo 电池 | 0.15–0.25 kWh/kg | 放电能力强、控制简单 |
| 汽油 | ~12 kWh/kg | 高两个数量级，但需发动机 |
| 甲醇/汽油两冲 | 8–11 kWh/kg | 小机型常用 |

一架 25 kg 电动六轴悬停 2.4 kW，20 分钟就要 800 Wh（约 4 kg 电池）。同重量汽油理论可支撑数小时——这就是油动/混动存在的理由。

## 2. 三种架构

| 架构 | 结构 | 优点 | 缺点 |
| --- | --- | --- | --- |
| 纯油直驱 | 发动机 → 减速箱 → 桨 | 结构简单、重量轻 | 转速响应慢、悬停控制难 |
| 串联混动（发电机） | 发动机 → 发电机 → 电调 → 电机 | 控制像电动、航时长 | 多一级能量转换、重量大 |
| 并联混动 | 发动机与电机共同驱动 | 功率互补 | 机构复杂、控制耦合 |

多旋翼几乎都走**串联混动**：发动机只负责发电，飞行控制仍由电驱完成，飞控不需要理解发动机的动态。

## 3. ArduPilot 的支持

- 固定翼/车船有内燃机支持（`AP_ICEngine`，参数族 `ICE_*`，覆盖启动、怠速、转速输入、点火输出等）；
- 多旋翼的混动通常把「发电机」当电源管理：由电源模块或 DroneCAN 设备上报电压/电流，飞控侧只做能量管理；
- 具体参数名随固件版本变化，使用前用 `paramdoc` 或官方参数表核对，不要照抄旧文档。

## 4. 控制难点

| 难点 | 表现 | 应对 |
| --- | --- | --- |
| 转速响应慢 | 油门变化后推力延迟数百毫秒 | 用电池缓冲瞬时功率，飞控侧仍按电调控制 |
| 振动频谱宽 | 发动机点火频率 + 谐波 | 多重陷波、加强减震、避免结构共振 |
| 油门-推力非线性 | 中低油门效率差 | 标定推力曲线，或固定工作点 |
| 启动/熄火 | 空中熄火失去能源 | 双路供电、自动重启、失效保护切电池 |
| 排气与散热 | 高温、废气影响 | 布局隔离、隔热、进气设计 |

## 5. 混动电气设计要点

1. **功率分配**：发电机额定功率 ≈ 巡航功率 × 1.2，电池负责峰值；
2. **母线电压**：与电调/电池匹配，DC-DC 效率计入能量预算；
3. **电池缓冲**：容量按「峰值功率持续时间」定，不要按总能量；
4. **能量管理**：剩余油量/电量双阈值，先到者触发返航；
5. **隔离**：发动机点火系统与飞控供电隔离，避免点火噪声串入。

## 6. 振动与滤波

发动机振动是**宽带 + 强谐波**，与电动完全不同：

- 点火频率 = 转速/60 × 气缸数/2（四冲程）；
- 需要多组陷波或更低的低通；
- 橡胶减震要按发动机重量选，太软会引入低频摆动；
- 结构上把发动机与飞控安装面分离。

## 7. 维护与安全

- 燃油系统：油箱防气泡、油管耐油、断油保护；
- 防火：排气远离线束，舱内阻燃；
- 启动前检查：油量、油路、点火、螺旋桨紧固；
- 飞行后：清理积碳、检查火花塞、记录运行小时数。

## 8. 选型判断

| 需求 | 建议 |
| --- | --- |
| 航时 < 40 min，载重 < 30 kg | 纯电：简单可靠 |
| 航时 1–3 h，载重 20–60 kg | 串联混动 |
| 长航时固定翼 | 纯油或混动 |
| 高频次、短周转 | 纯电（换电池比加油快） |
