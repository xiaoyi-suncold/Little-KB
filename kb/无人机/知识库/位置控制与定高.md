# 位置控制与定高

> 定点模式「画圈」、定高模式「掉高」，大多不是姿态环的问题，而是位置环或高度源的问题。

## 1. 三层结构

```
位置误差 (m) ──►[P]──► 期望速度 (m/s) ──►[PID]──► 期望加速度 ──► 姿态/油门
```

- **水平（NE，North-East）**：`PSC_NE_POS_P` → `PSC_NE_VEL_P/I/D` → 倾斜
- **垂直（D，Down）**：`PSC_D_POS_P` → `PSC_D_VEL_P/I/D` → `PSC_D_ACC_P/I/D` → 油门

4.8 之前叫 `PSC_POSXY_P`、`PSC_VELXY_*`、`PSC_POSZ_P`、`PSC_VELZ_*`、`PSC_ACCZ_*`，换算关系见 [参数体系与命名迁移](参数体系与命名迁移.md)。

## 2. 各层的作用

| 层 | 参数 | 作用 | 调大的后果 |
| --- | --- | --- | --- |
| 位置 | `PSC_NE_POS_P` / `PSC_D_POS_P` | 距离误差 → 期望速度 | 到位更快，过大则冲过头再回来 |
| 速度 | `PSC_NE_VEL_P` / `PSC_D_VEL_P` | 速度误差 → 期望加速度 | 抗风更强，过大高频抖 |
| 速度积分 | `PSC_*_VEL_I` | 消除稳态速度误差（风） | 消除漂移，过大低频慢摆 |
| 速度微分 | `PSC_*_VEL_D` | 抑制速度突变（刹车阻尼） | 刹车更干脆 |
| 加速度 | `PSC_D_ACC_P/I/D` | 垂直加速度 → 油门 | 高度响应更硬，过大诱发 4 Hz 振荡 |

**垂直环特殊**：加速度环直接输出油门，所以它和 `MOT_THST_HOVER`（悬停前馈）是耦合的。加速度环太软表现为「掉高、爬升慢」，太硬表现为「高度抖动」。

## 2.5 垂直环路增益与悬停油门（4 Hz 抖动的根因）

垂直通道的稳定性不只取决于增益，还取决于**工作点**。悬停油门 `h` 越低，同样的油门变化产生的加速度越大：

```
油门→加速度增益 ≈ g / h        （g = 9.81 m/s²）
垂直环路指标   ≈ (PSC_D_ACC_P × PSC_D_VEL_P) / h
```

- 常规机型 h≈0.5，默认 0.5×5.0=2.5 → 指标 5.0；
- h=0.20（动力过剩）→ 指标 12.5，约为常规的 2.5 倍；
- h=0.125 → 指标 20，约为常规的 4 倍。

再叠加滤波器相位滞后（10 Hz 二阶低通在 4 Hz 约滞后 34°，15 Hz 约 22°）与 10 Hz 控制周期、电机响应延迟，总延迟 150–200 ms 时，相位在 3–4 Hz 到达 180°，形成**等幅极限环**。表现为：高度几乎不动（毫米级），但油门与 Z 轴加速度以 4 Hz 同步摆动，电机听起来一抽一抽。

**处置顺序**：
1. 先把工作点拉回可控区间——换小桨/降电压/减重，让 h 回到 0.30–0.50；
2. 按 `h` 折算增益：`PSC_D_ACC_P × PSC_D_VEL_P ≈ 2.5 ~ 4`（相对常规的 0.5–0.8 倍）；
3. 提高加速度低通截止（10→15 Hz）换回相位裕度；
4. 冻结悬停学习（`MOT_HOVER_LEARN=0`），避免 `h` 越学越低；
5. 不要用 D 项去压 4 Hz，D 对延迟更敏感。

> 这条结论来自本项目 14S 四轴清洗机的实测：h=0.125、AccZ 97.6% 方差集中在 4.00 Hz、视频独立验证 3.98 Hz。详见 `kb/无人机/项目/4Hz 垂直抖动复盘.md`。

## 3. 定高不稳的诊断顺序
| 现象 | 首要嫌疑 | 验证 |
| --- | --- | --- |
| 悬停高度缓慢下沉 | 悬停油门偏低 / 电压补偿 | 看 `CTUN.ThO` 与 `MOT_THST_HOVER` 是否匹配 |
| 高度高频抖（4–5 Hz） | 垂直加速度环太硬 / 振动 | 降 `PSC_D_ACC_P`，查 `VIBE` |
| 爬升/下降迟钝 | `PSC_D_VEL_P` 偏小 | 小幅加 |
| 到位后上下过冲 | `PSC_D_POS_P` 偏大或 D 不足 | 降位置 P，加 `PSC_D_VEL_D` |
| 载重变化后高度差 | 悬停油门未自适应 | 开 `MOT_HOVER_LEARN`，或按载重分参数组 |
| 满电窜、低电软 | 未设电压补偿 | 设 `MOT_BAT_VOLT_MAX/MIN` |

## 4. 抗风与刹车

- **风**：`PSC_NE_VEL_I` 消除持续风速偏差；`PSC_NE_VEL_P` 决定阵风下的刚度。
- **刹车**：`PSC_NE_VEL_D` + `LOIT_BRK_*`（制动加速度/延迟/ jerk）决定松杆后停得多干脆。刹太狠会点头，太软会飘。
- **风估计**：EKF 会估计风速，`PSC_*` 与 `LOIT_*` 共同决定抗风表现；不要用软件参数去补机械动力不足。

## 5. 定点画圈/漂移的排查

1. 罗盘/航向：航向偏 → 位置环把机体往错的方向拉 → 画圈；
2. EKF 方差：融合在犹豫 → 位置输出抖；
3. 振动：高频振动进入加速度计 → 位置漂；
4. `PSC_NE_VEL_I` 过大：低频绕圈；
5. 电机不同步/机架扭曲：一侧推力偏差，位置环持续修正。

顺序：航向 → EKF → 振动 → 最后才是位置环参数。
