# 参数体系与命名迁移（ArduPilot Copter）

> 只讲「参数是什么、属于哪一层」，不讲某台机的具体取值。
> 依据：ArduPilot Copter 4.8-dev 官方参数文档 + 本次入库的 1127 条参数语义。

## 1. 控制链的分层

多旋翼飞控的参数不是一堆散点，而是按**控制回路层级**组织的：

```
位置环 (Position)  ── 距离误差 → 期望速度
    ↓
速度环 (Velocity)  ── 速度误差 → 期望加速度
    ↓
加速度环 (Accel)   ── 加速度误差 → 油门/姿态指令
    ↓
姿态环 (Attitude)  ── 角度误差 → 期望角速度
    ↓
角速度环 (Rate)    ── 角速度误差 → 力矩 → 电机混控
```

调参顺序与这个层级一致：**先内环后外环**。内环（角速度）没调好，外环（角度/位置）怎么调都会摆。

## 2. 参数族速查

| 前缀 | 层级/系统 | 典型参数 | 作用 |
| --- | --- | --- | --- |
| `ATC_` | 姿态控制 | `ATC_ANG_RLL_P`、`ATC_RAT_RLL_P/I/D`、`ATC_ANGLE_MAX`、`ATC_INPUT_TC` | 角度环 + 角速度环 + 输入整形 |
| `PSC_` | 位置控制 | `PSC_NE_POS_P`、`PSC_NE_VEL_P`、`PSC_D_VEL_P`、`PSC_D_ACC_P` | 水平(NE)/垂直(D)三层环 |
| `MOT_` | 动力输出 | `MOT_THST_HOVER`、`MOT_THST_EXPO`、`MOT_SPIN_MIN/ARM`、`MOT_PWM_MIN/MAX` | 油门到推力的映射 |
| `INS_` | IMU | `INS_GYRO_FILTER`、`INS_ACCEL_FILTER`、`INS_HNTCH_*` | 采样、滤波、陷波 |
| `EK3_` | 导航滤波 | `EK3_SRC1_*`、`EK3_ENABLE` | GPS/IMU/气压/测距融合 |
| `AHRS_` | 姿态估计 | `AHRS_TRIM_*`、`AHRS_RP_P` | 互补滤波与安装偏差 |
| `BATT_` | 电源 | `BATT_MONITOR`、`BATT_VOLT_MULT`、`BATT_AMP_PERVLT`、`BATT_FS_*` | 电压电流标定与低电量保护 |
| `FENCE_` / `FS_` | 安全 | `FENCE_ENABLE`、`FENCE_TYPE`、`FS_EKF_ACTION`、`FS_THR_ENABLE` | 围栏与失效保护 |
| `WPNAV_` / `RTL_` / `LAND_` | 任务 | `WPNAV_SPEED`、`RTL_ALT`、`LAND_SPEED` | 航点、返航、降落速度 |
| `SR*_` | 遥测 | `SR1_POSITION`、`SR1_EXTRA1` | 各串口 MAVLink 消息速率 |
| `RC*_` / `SERVO*_` | 输入输出 | `RC1_MIN/MAX/TRIM`、`SERVO1_FUNCTION` | 通道映射与行程 |

## 3. 4.6 → 4.8 的命名迁移（重要）

4.8-dev 文档已经把一批「历史遗留名字」换成结构化命名。**照着老教程改参数会找不到名字**。

| 旧名（≤4.7） | 新名（4.8+） | 说明 |
| --- | --- | --- |
| `ANGLE_MAX` | `ATC_ANGLE_MAX` | 最大倾角，语义不变 |
| `ARMING_CHECK` | `ARMING_SKIPCHK` | **语义反转**：旧的是「启用哪些检查」的位掩码，新的是「跳过哪些检查」，默认 0=不跳过 |
| `GPS_TYPE` | `GPS1_TYPE` | GPS 主副编号前置 |
| `GPS_RATE_MS` | `GPS1_RATE_MS` | 同上 |
| `GPS_POS1_X/Y/Z` | `GPS1_POS_X/Y/Z` | 编号位置变了，不是同一个字符串 |
| `GPS_MB_OFS_*` | `GPS_MB1_OFS_*` | 移动基线编号 |
| `PSC_POSXY_P` | `PSC_NE_POS_P` | NE = North-East（水平） |
| `PSC_VELXY_P/I/D` | `PSC_NE_VEL_P/I/D/FF` | 官方文档写明 "Previously _VELXY_P" |
| `PSC_POSZ_P` | `PSC_D_POS_P` | D = Down（垂直） |
| `PSC_VELZ_P` | `PSC_D_VEL_P` | "Previously _VELZ_P" |
| `PSC_ACCZ_P/I/D` | `PSC_D_ACC_P/I/D` | **单位缩放 ×0.1**：官方原文 "If upgrading from 4.6 this is _ACCZ_P * 0.1" |

### 升级时最容易踩的三个坑

1. **`PSC_D_ACC_*` 不是简单改名，是重新标定**：4.6 的 `PSC_ACCZ_P=0.30` 对应 4.8 的 `PSC_D_ACC_P=0.03`。直接抄旧值会让垂直环增益放大 10 倍。
2. **`ARMING_CHECK` 语义反转**：旧的 `ARMING_CHECK=334`（启用 5 项检查）在新固件里应写成 `ARMING_SKIPCHK` 的补集，而不是 334。
3. **GPS 编号顺序变了**：`GPS_POS1_X` 不是 `GPS1_POS_X` 的同义字符串，按名字批量替换会漏。

## 4. 怎么判断自己在哪个版本

不用查固件号，看参数名就行：

| 现象 | 推断 |
| --- | --- |
| 参数里有 `PSC_NE_*` / `PSC_D_*` | 4.8 或更新 |
| 参数里有 `PSC_POSXY_P` / `PSC_ACCZ_P` | 4.6 及更早 |
| 有 `ANGLE_MAX`、没有 `ATC_ANGLE_MAX` | ≤4.7 |
| 有 `ARMING_SKIPCHK` | 4.7+ |
| 有 `GPS1_*` 且无 `GPS_*` | 4.6+ |

本次入库的两份表都属于**旧命名体系**（`ANGLE_MAX`、`ARMING_CHECK`、`GPS_*`、`PSC_ACCZ_*`），说明它们不是从 4.8 设备导出的。

## 5. 查语义的方式

```bat
python scripts\kb.py paramdoc ATC_RAT_RLL_D
python scripts\kb.py paramdoc --category 姿态控制
python scripts\kb.py paramdoc -k 前馈
```

语义库里 1127 条参数，其中 966 条在 4.8 文档中仍存在；其余标注为「旧版/厂商/已废弃」或给出新名字。

## 6. 参数名之外的三条判断

- **看层级**：改一个参数前先问它属于哪一环。改外环去救内环问题，只会掩盖症状。
- **看单位**：很多参数带单位（0.01°、cm/s、m/s²、百分比），不同版本可能改标定，抄数值前先抄单位。
- **看依赖**：`MOT_THST_HOVER` 依赖实际重量与电压；`ATC_*` 依赖振动与滤波。孤立地看一个参数没有意义。
