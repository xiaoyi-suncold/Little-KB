# 固定翼与 VTOL（QuadPlane）

> 多旋翼靠推力矢量控制位置，固定翼靠**能量**。这是两套完全不同的控制哲学。

## 1. 固定翼的控制链

```
滚转：副翼 → 滚转角速度/角
俯仰：升降舵 → 俯仰角
偏航：方向舵 → 侧滑/协调转弯
油门：总能量
```

固定翼没有「悬停油门」的概念：**油门决定总能量，俯仰决定能量在高度与速度之间怎么分配**。

## 2. TECS：总能量控制

```
总能量 E = m·g·h + ½·m·v²
```

- 油门负责把总能量维持在期望值；
- 俯仰负责把能量在「势能（高度）」和「动能（速度）」之间重新分配；
- 下降时低头，势能转动能；爬升时抬头，动能转势能。

`TECS_SPDWEIGHT` 决定俯仰更偏向管速度还是管高度：

| 取值 | 行为 | 适用 |
| --- | --- | --- |
| 0.0 | 俯仰只管高度，忽略速度误差 | 高度精度优先 |
| 1.0（默认） | 速度与高度同时兼顾 | 通用 |
| 2.0 | 俯仰只管速度，忽略高度 | 滑翔机 |

**没有空速计时**，TECS 退化为「俯仰管高度、油门跟随俯仰」，速度权重实际为 0。

## 3. TECS 关键参数（按调参顺序）

| 顺序 | 参数 | 含义 | 定法 |
| --- | --- | --- | --- |
| 0 | 空速计标定 | 空速准确性 | 见官方标定流程 |
| 0 | 俯仰→舵机环 | 内环必须已调好 | `PTCH2SRV_*` / AUTOTUNE |
| 1 | `THR_MAX` | 最大油门 | 能以最大俯仰角爬升、且不失速 |
| 2 | `TRIM_THROTTLE` | 巡航油门 | 平飞巡航速度时的油门 |
| 3 | `AIRSPEED_MIN` / `MAX` / `CRUISE` | 速度边界 | 失速速度与最大平飞速度之间 |
| 4 | `PTCH_LIM_MAX_DEG` / `MIN_DEG` | 俯仰边界 | 最大爬升不失速、最大下降不超速 |
| 5 | `TECS_CLMB_MAX` / `SINK_MIN` / `SINK_MAX` | 爬升/下沉率边界 | 实测，电动力按末端电压留 20% 余量 |
| 6 | `TECS_TIME_CONST` | 响应时间常数 | 高度振荡时加大（1→10） |
| 7 | `TECS_PTCH_DAMP` | 俯仰阻尼 | 高度振荡加 0.1 步进 |
| 8 | `TECS_THR_DAMP` / `TECS_INTEG_GAIN` | 油门阻尼/积分 | 速度振荡时调 |
| 9 | `TECS_RLL2THR` | 转弯补偿油门 | 约 10× 45° 盘旋的额外下沉率 |
| 10 | `TECS_PTCH_FF_K` / `V0` | 速度前馈 | 滑翔机常用，负值 |

## 4. 试飞判据（官方口径）

- 爬升指令 50 m 以上：油门约 `THR_MAX` 的 80%、空速保持、俯仰距上限约 5°；
- 下降指令 50 m 以上：油门到 `THR_MIN`、空速不超过 `AIRSPEED_MAX`、俯仰距下限约 5°；
- 盘旋定高：高度波动 < 10 m，无明显俯仰振荡。

不满足时先改限值（`THR_MAX`、`PTCH_LIM_*`、`TECS_CLMB_MAX`），再动阻尼/时间常数——**限值错误会让阻尼怎么调都振荡**。

## 5. VTOL：QuadPlane 的参数族

QuadPlane 是 Plane 固件里的一个选项，`Q_ENABLE=1` 后才会出现 `Q_*` 参数：

| 参数族 | 作用 |
| --- | --- |
| `Q_ENABLE` | 总开关 |
| `Q_FRAME_CLASS` / `Q_FRAME_TYPE` | 多旋翼构型 |
| `Q_M_*` | 电机与推力缩放 |
| `Q_A_*` | VTOL 姿态控制（角度/角速度环） |
| `Q_P_*` | VTOL 位置控制 |
| `Q_TRANSITION_MS` | 过渡时间 |
| `Q_TILT_*` | 倾转机构角度与速率 |
| `Q_TAILSIT_*` | 尾座式专用 |
| `Q_ASSIST_*` | 固定翼模式下的多旋翼辅助 |

**关键事实**：VTOL 模式与固定翼模式使用**两套独立的调参**（`Q_A_*` vs `ATC_*`），不要互抄。

## 6. 过渡段的风险

1. **失速**：固定翼速度未建立就收 VTOL 推力；
2. **倾转卡死**：舵机/连杆失效，飞机处于半过渡状态；
3. **重心偏移**：VTOL 电机与机翼的相对位置改变悬停配平；
4. **尾座式起降**：地面风与起落架接触瞬间的力矩。

处置：过渡高度与速度留足余量；`Q_TRANSITION_MS` 不要压太短；每次改倾转参数都要做一次完整过渡测试。

## 7. 选型对比

| | 多旋翼 | 固定翼 | VTOL |
| --- | --- | --- | --- |
| 悬停 | 天然 | 不能 | 可以 |
| 巡航效率 | 低 | 高 | 中 |
| 结构复杂度 | 低 | 中 | 高 |
| 失效模式 | 掉高/翻 | 失速/螺旋 | 过渡失败 |
| 适用 | 短距、贴合作业 | 长航时测绘 | 无跑道起降 + 长航程 |
