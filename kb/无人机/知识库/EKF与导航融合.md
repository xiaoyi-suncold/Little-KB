# EKF3 与导航融合

> EKF 是飞控的「认知层」：把一堆有噪声、有延迟、偶尔撒谎的传感器，融合成姿态、位置、速度、风。

## 1. 它融合什么

| 传感器 | 提供 | 弱点 |
| --- | --- | --- |
| IMU（陀螺+加速度计） | 角速度、比力，高频、低延迟 | 积分漂移 |
| 气压计 | 高度 | 受温度、气流、地效影响 |
| GPS | 位置、速度、航向（移动时） | 多路径、遮挡、跳变 |
| 罗盘 | 航向 | 电机电流与铁磁干扰 |
| 测距仪 | 低空高度 | 量程、地面反射 |
| 光流/视觉 | 水平速度/位置（无 GPS） | 纹理、光照、高度依赖 |
| 空速管（VTOL/固定翼） | 空速 | 安装误差、结冰 |

EKF3 用误差状态卡尔曼滤波维护：姿态、位置、速度、陀螺零偏、加速度计零偏、地磁、风、气压基准等状态，并输出各自的**方差**（不确定度）。

## 2. 源选择：告诉 EKF 信谁

| 参数 | 含义 | 常见来源 |
| --- | --- | --- |
| `EK3_SRC1_POSXY` | 水平位置源 | GPS / 光流 / 视觉 |
| `EK3_SRC1_VELXY` | 水平速度源 | GPS / 光流 |
| `EK3_SRC1_POSZ` | 高度源 | 气压 / 测距 / GPS |
| `EK3_SRC1_VELZ` | 垂直速度源 | 气压 / GPS |
| `EK3_SRC1_YAW` | 航向源 | 罗盘 / GPS 移动基线 / 外部 |

`EK3_SRC2_*`/`SRC3_*` 是备用源，主源失效时可切换。**切换不是自动万能的**：源之间必须有可比的观测量，否则切换瞬间会跳变。

## 3. 航向的三条路线

1. **罗盘**：便宜、全局，怕电流与铁磁干扰；双罗盘做一致性检查。
2. **GPS 移动基线（双天线）**：不受磁干扰，但需要两天线固定基线（`GPS_MB1_OFS_*`），且依赖卫星质量。
3. **视觉/外部导航**：室内或强干扰环境，成本高。

多旋翼在高压大电流平台上，罗盘被电源线干扰是常见故障源，改用移动基线是工程上的正解之一。

## 4. 健康判据

| 现象 | 看什么 | 说明 |
| --- | --- | --- |
| 定点画圈/漂移 | `XKF1.PN/PE` 与期望偏差、`XKF4.SV`（状态方差） | 方差大 = 融合在犹豫 |
| 高度缓慢漂 | `XKF1.PD` 与气压差、`BARO` 温漂 | 气压基准随温度漂 |
| 航向突然跳 | `XKF1.YAW` 阶跃、罗盘 `MAG` 值 | 干扰或校准不良 |
| `EKF3 IMU0 lane switch` | 日志事件 | 主 lane 不健康，已切备用 |
| 解锁报 `EKF variance` | `XKF4` | 方差未收敛就解锁 |

## 5. 关键参数

| 参数 | 作用 |
| --- | --- |
| `EK3_ENABLE` | EKF3 总开关 |
| `EK3_IMU_MASK` | 参与融合的 IMU 位掩码 |
| `EK3_ALT_SOURCE` | 高度主源（部分版本） |
| `EK3_GLITCH_RAD` | GPS 位置跳变门限（米） |
| `EK3_GBIAS_*` | 陀螺零偏学习 |
| `EK3_ACC_*` / `EK3_GYRO_*` | 噪声与偏置过程参数 |
| `AHRS_EKF_TYPE` | 使用 EKF2/EKF3/外部 |

## 6. 常见故障与处置

| 故障 | 根因 | 处置 |
| --- | --- | --- |
| 罗盘不一致（Compass variance） | 电流干扰、校准在通电状态下做 | 抬高校准、双罗盘取舍、改移动基线 |
| GPS 跳变导致位置猛拉 | 多路径、卫星几何差 | 提高 HDOP 门限、开 `GPS_*_MIN_DGPS`、换安装位置 |
| 气压漂移导致掉高 | 温度、气流 | 开气压温补、加海绵、改用测距近地 |
| EKF 频繁 lane switch | 某个 IMU 振动或饱和 | 查 `VIBE` 与该 IMU 的 `AccX` |
| 室内无 GPS 无法定点 | 无外部源 | 光流/视觉 + 测距，`EK3_SRC1_POSXY` 改光流 |

## 7. 调 EKF 的边界

EKF 参数（噪声、门限）不是「调参」能解决的性能问题。**先修传感器安装与干扰，再谈参数**。把 `EK3_GLITCH_RAD` 放大只会让跳变更难被发现，不会让定位更准。
