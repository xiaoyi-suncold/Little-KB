# 传感器与标定

> 标定错误不会被「调参」救回来，只会伪装成控制问题。

## 1. 顺序（错了会互相污染）

1. **IMU 六面校准**（水平、倒置、四侧）→ 得到 `INS_ACC*_OFS`、`INS_GYRO*_OFS`；
2. **罗盘校准**（远离电源线，最好做电机电流补偿 `COMPASS_MOT`）；
3. **水平校准**（`AHRS_TRIM_X/Y`）——机架放在水平面上做，别用参数去补倾斜的桌子；
4. **气压基准**（`BARO*_GND_PRESS` 上电自动记录，别手动改）；
5. **GPS 安装位置**（`GPS1_POS_X/Y/Z`，相对重心，单位米）；
6. **电源模块标定**（电压/电流）；
7. **遥控行程与通道**（`RC*_MIN/MAX/TRIM`）；
8. **电调行程/协议**（`MOT_PWM_MIN/MAX`、DShot/DroneCAN）。

## 2. IMU

| 参数 | 含义 | 注意 |
| --- | --- | --- |
| `INS_ACC*_OFS_*` | 加速度计零偏 | 由六面校准生成 |
| `INS_ACC*_SCAL_*` | 加速度计比例 | 一般不动 |
| `INS_GYRO*_OFS_*` | 陀螺零偏 | 上电静止时自动学习 |
| `INS_ACCEL_FILTER` / `INS_GYRO_FILTER` | 低通 | 见 [振动滤波与陷波](振动滤波与陷波.md) |
| `INS_HNTCH_*` | 陷波 | 同上 |
| `INS_USE*` / `INS_IMU_MASK` | 启用哪些 IMU | 双 IMU 冗余 |

**安装方向**：`AHRS_ORIENTATION` 必须与实际安装一致，否则姿态永远歪。改了要重新校准。

## 3. 罗盘

| 参数 | 含义 |
| --- | --- |
| `COMPASS_OFS*_X/Y/Z` | 硬铁偏移 |
| `COMPASS_DIA*_X/Y/Z` | 软铁椭球校正 |
| `COMPASS_ODI*_X/Y/Z` | 软铁非正交校正 |
| `COMPASS_MOT*_X/Y/Z` | 电机电流磁干扰补偿 |
| `COMPASS_EXTERN*` | 外置罗盘 |
| `COMPASS_PRIO*_ID` | 罗盘优先级 |
| `COMPASS_LEARN` | 飞行中自动学习 |

**关键实践**：
- 校准要在「通电、电机不转」和「电机转」两种状态下分别做，前者去硬铁，后者去电流干扰；
- 高压大电流平台，罗盘尽量装在机臂末端/ GPS 杆顶，远离电源线；
- 双罗盘要做一致性检查，不一致时优先信外置。

## 4. GPS

| 参数 | 含义 |
| --- | --- |
| `GPS1_TYPE`（旧 `GPS_TYPE`） | 协议类型（uBlox/DroneCAN/MAVLink…） |
| `GPS1_POS_X/Y/Z` | 相对重心位置 |
| `GPS1_RATE_MS` | 更新率（5 Hz = 200 ms） |
| `GPS_MB1_OFS_*` | 双天线基线（移动基线测向） |
| `GPS1_GNSS_MODE` | 星座选择 |

**移动基线**：两天线基线长度与方向必须实测填入，否则航向会系统性偏。

## 5. 气压计

- 基准 `BARO*_GND_PRESS` 是**上电瞬间**的地面气压，不是标准大气压；
- 温度变化会导致漂移，可用温补参数（`TCAL_*`）或加海绵隔热；
- 近地作业优先用测距仪做高度源，气压只作备份。

## 6. 标定后的验证清单

- [ ] 静止时 `ATT.Roll/Pitch` ≈ 0（±1°）
- [ ] 航向与实景一致，转动时无跳变
- [ ] 抬起一侧看 `ATT.Roll` 方向正确
- [ ] 电机转动时罗盘值变化 < 阈值（做 `COMPASS_MOT` 前后对比）
- [ ] 电压读数与万用表一致（±0.1 V）
- [ ] 电流读数与钳形表一致（±5%）
- [ ] 遥控各通道行程到满、方向正确

## 7. 常见错误

1. 在倾斜的桌面上做水平校准；
2. 罗盘校准在电源线旁边做，飞起来航向乱跳；
3. 改了 `AHRS_ORIENTATION` 不重新校准；
4. 双 GPS 只接一个，另一个参数还开着「必需」；
5. 电源模块没标定，低电量保护按错误电压触发。
