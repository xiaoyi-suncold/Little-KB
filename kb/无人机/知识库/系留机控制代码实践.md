# 系留机控制代码实践：搬 MATLAB → 复现 → 自建一致模型

> 第四篇。前一篇只读到论文摘要，这一篇是真读了代码：GitHub `sof-danny/TUAV_system_control`
> 五个文件共 467 行（main 164 / dynamics 131 / cableDynamics 19 / draw_drone 59 / get_rotation 13），
> 搬到 Python 跑，跑出问题，查清原因，然后自己按物理一致的方式重写一版。
> 产物：`scripts/tuav_sim.py`（忠实搬迁，含诊断）与 `scripts/tuav_model.py`（自建一致模型）。

## 一、结论

1. **原仓库代码直接搬过来是不可用的**：最高速度跑到 **183 m/s**、航点 0.1 s 就"到达"——那是数值发散，不是飞行。
2. 根因两条：
   - `dynamics.m` 的 z 轴加速度里，重力项与推力项**符号反了**（`... + m*g*C_theta*C_phi + Tz ...`），推力被重力"加成"而不是抵消；
   - 姿态控制律拿**角度**当角速度反馈（`U_phi = Ixx*(-k8*z4 - x7 - k7)`，应为 `-x8` 角速度）。
3. 修正这两处后仍不收敛到可行轨迹，于是按标准多旋翼动力学重写（`tuav_model.py`），结果合理：四点航点 20→40→60→100 m 依次到达，末点误差 1.6 m，峰值张力 82.8 N（8.4 kg），稳态张力 16 N。
4. **与静态模型互校通过**：静态悬链线脚本算 100 m 悬停约 17.8 N，动态模型稳态 16.1 N —— 同一量级，差在动态模型把缆当线性弹簧。
5. 加 5 N 横风（≈8 m/s，等效 2.84 kg 机体的阻力）+ 1 N 阵风扰动，末点误差 0.64 m、峰值张力 189 N：**风不改变能不能悬停，只抬高张力峰值和瞬态**。

## 二、原仓库模型拆解（读代码得到的结构）

状态 14 + 2n：
```
x, vx, y, vy, z, vz, roll, p, pitch, q, yaw, r, 缆长 l, 缆长变化率
+ 缆绳 n 个集中质量的位移/速度（弹簧-阻尼，仅表现"抖动"）
```
- 位置环：backstepping，误差 `e1..e12`，中间变量 `z1..z6 = ė + k·e`。
- 姿态输入：`Uf1/Uf2/Uf3` 三个方向虚拟推力，按 `den1..den3`（角度三角组合）解耦。
- 绞车：`U_win` 让缆长跟踪 `x13_ref = sqrt(2a·sinh(x/(2a)) + z²)`——**就是"按当前几何算悬链线所需长度"**，与上一篇张力模型的悬链线方程同源。
- 张力：`Th = T0 + rho·s·z·g`，再按 `alpha_angle`、`beta = atan(sinh((x-x0)/a))` 分解到三轴——**张力只按位置静态算，没有考虑缆的自重垂度变化**。
- 缆湍流层：`cableDynamics.m` 只做一维弹簧-阻尼，首尾节点导数强制为 0，作用仅是给动画加"抖动"。

参数（照搬）：`m=2.84 kg`，`Ixx/Iyy/Izz = 0.5192/0.4929/0.0947`，`l=0.405 m`，`Iw=0.01`，`r_w=0.1 m`，`rho=0.034`，`s=1.1e-4 m²`，`T0=5 N`，增益 `k1..k14` 见源码。

## 三、搬迁跑出来的问题（可复现）

```
python scripts/tuav_sim.py

=== 原文参数（角速度反馈用角度） ===
仿真 30s 完成，航点 #3，位置 (1.96, 9.92, 9.98)
距目标 0.09 m｜缆长 10.07 m（期望 10.08 m，差 0.01 m）
最高速度 183.05 m/s｜到达航点时刻 #1@0.1s, #2@0.2s, #3@0.4s
```
- 最高速度 183 m/s 是四旋翼不可能的量级（真实机型上限 20–30 m/s）；
- 航点 0.1 s 内"到达"，说明位置是瞬间跳过去的，不是飞过去的；
- 三种改法（只改角速度反馈 / 再加俯仰参考 0）结果完全一致——说明主因不在增益，而在方程符号。

**判定**：这份代码作为论文配图能跑到"看起来像"，但作为可复用的仿真底座不安全，直接照抄控制律会把人带沟里。

## 四、自建一致模型（scripts/tuav_model.py）

结构：
- 刚体：位置/速度/姿态角/角速度，推力沿机体 z，重力 −g；
- 控制：位置 PID（`kp=0.9, kd=1.8, ki=0.25`，加速度限幅 0.4 g）→ 姿态反解 `pitch=a_x/g, roll=−a_y/g` → 姿态 P-D 出力矩；
- 系缆：`|p| > 0.995·l` 视为绷紧，按 `K=400 N/m`、`C=8 N·s/m` 的弹性-阻尼给径向拉力，否则松弛不受力；
- 绞车：跟随"当前位置悬链线所需长度"，速度限 ±2 m/s（对应标准 5.3.9 b 的 ≥2 m/s 量级）；
- 风：常值力 + 正弦阵风扰动。

实跑结果：
```
== 情形1：无风，四点航点（垂直 20→40→60→100 m）==
最终航点 #4，距目标 1.60 m
最高速度 12.94 m/s｜峰值缆张力 82.8 N（8.44 kg）
到达时刻 #1@26.8s, #2@38.9s, #3@49.3s
  t=  40s 位置 (15.72, 2.22, 41.63) 缆长 44.8 m 张力 16.2 N
  t=  60s 位置 (-1.37, -1.72, 84.32) 缆长 84.8 m 张力 16.1 N

== 情形2：横风 ≈8 m/s（等效 5 N 阻力）+ 1 N 阵风扰动 ==
最终航点 #4，距目标 0.64 m｜最高速度 13.79 m/s｜峰值张力 189.3 N
```

读法：
- 巡航时缆张力约 16 N ≈ 1.6 kg，与静态悬链线算的 17.8 N 同量级 → **两个独立实现互校通过**；
- 峰值 83 N / 189 N 出现在**加速爬升把缆拽紧的瞬态**，不是稳态——这就是为什么工程上要按动载（×1.5–2）而不是按静态张力选缆和接插件；
- 有风时稳态误差反而小（0.64 m vs 1.6 m）：风把缆吹成弧形，缆的回复力帮忙"拉住"了机位；但峰值张力翻倍，绞车与接插件承受的是峰值。

## 五、和标准、论文对上了什么

| 来源 | 说法 | 本次实践验证到的东西 |
| --- | --- | --- |
| arXiv:2412.09502 | 机载管位置姿态、地面管缆长保持悬链形态 | 绞车的 `l_ref` 必须由当前位置反算，不能开环放线；否则缆张紧瞬间的冲量直接把机拉飞（峰值张力 189 N） |
| T/CECS 5.3.9 b | 收放线速度 ≥2 m/s | 模型里把绞车速度限在 ±2 m/s，跟踪 100 m 高度变化需要 50 s 以上——**升限速度受绞车限制**，不是飞控 |
| T/CECS 5.3.5 | 跟随精度水平 ≤5 m | 模型末点误差 0.64–1.6 m，说明只要缆长跟随对，5 m 精度对 PID 是宽松指标 |
| CN113885545B | 张力按几何静态算会低估瞬态 | 稳态 16 N vs 峰值 189 N，差一个数量级，印证"必须算张力变化"而不是取最大值 |

## 六、边界与失败模式（自建模型）

- 小角度近似：姿态超过 ~30° 时 `pitch=a_x/g` 失效，大机动要换成完整旋转矩阵。
- 缆是线性弹簧：没有垂度、没有缆自重随高度变化、没有横向波传播（真实缆会像弦一样摆动，可能诱发低频振荡）。
- 没有旋翼动力学（一阶推力滞后、桨叶挥舞）、没有电机饱和曲线、没有电池压降。
- 绞车只有速度限，没有惯量与卷径变化（真实绞车卷径变大，线速度与角速度换算非线性）。
- 风是常值 + 正弦，不是湍流谱（Dryden/von Kármán）。
