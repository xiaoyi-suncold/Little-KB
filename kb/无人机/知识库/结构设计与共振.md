# 结构设计与共振

> 结构决定了振动的下限。飞控只能滤波，改不了机架的固有频率。

## 1. 轴距与桨径

X 型四轴的几何关系：

```
相邻电机间距 = 轴距 / √2        （轴距 = 对角电机距离）
桨尖间隙 = 相邻电机间距 − 桨径  ≥ 5%~10% 桨径
```

例：轴距 1200 mm → 相邻间距 849 mm；用 28 寸桨（711 mm）→ 桨尖间隙 138 mm（约 19%），偏宽松；用 30 寸（762 mm）→ 87 mm（11%），可接受。

六轴（Y6 或平铺六轴）要按实际布局算相邻间距，不能直接套四轴公式。

## 2. 刚度与固有频率

机臂一阶弯曲频率必须远离激励频率：

```
f_arm > 2 × BPF（桨叶通过频率）
```

28 寸桨 2600 RPM → BPF ≈ 87 Hz → 机臂一阶频率最好 > 175 Hz。碳管直径、壁厚、长度直接决定这个值：

- 加粗管径比加厚壁厚更有效（惯性矩 ∝ D⁴）；
- 缩短悬臂长度最有效；
- 折叠机构是刚度杀手，折叠处要加套筒/锁紧。

## 3. 共振的识别

1. **敲击法**：装桨前敲机臂，用加速度计或手机测频谱；
2. **悬停扫频**：缓慢加减油门，观察 `VIBE` 与频谱主峰是否随转速移动（移动的是 BPF，固定的是结构共振）；
3. **地面测试**：不同转速下测机体振动，找共振点。

固定频率的峰不随油门变化 → 结构共振；随转速线性变化 → 桨/电机。

## 4. 重心与惯量

- 重心尽量靠近几何中心，且 Z 向尽量低；
- 大惯量会让姿态环响应变慢（`τ = I·α`），内环增益要相应降低；
- 载荷（水箱）位置变化会移动重心，需要：
  - 结构上把水箱放在重心附近；
  - 软件上按载重分参数组，或依赖 `MOT_HOVER_LEARN` 自适应。

## 5. 材料与工艺

| 部位 | 常用 | 要点 |
| --- | --- | --- |
| 机臂 | 碳纤维圆管/方管 | 壁厚 ≥ 1.5 mm，接头加衬套 |
| 中心板 | 碳板 + 铝合金 | 螺丝孔加沉头，避免层间撕裂 |
| 起落架 | 碳管/尼龙 | 要有缓冲，避免硬着陆传递冲击 |
| 电机座 | 铝合金 | 与管壁贴合面 ≥ 80% |

## 6. 防水与防护（清洗/植保场景）

- 电机选防水型（IPX5 以上），电调灌封；
- 飞控放在独立密封舱，气压计要留透气孔且防溅；
- 接插件用防水航插，线束做滴水弯；
- 清洗液的腐蚀性要单独评估（pH、溶剂），密封圈材质选氟橡胶。

## 7. 结构设计校核清单

- [ ] 桨尖间隙 ≥ 5% 桨径
- [ ] 机臂一阶频率 > 2×BPF
- [ ] 重心在几何中心 ±5% 轴距内
- [ ] 满载与空载的重心偏移可接受
- [ ] 折叠/接头处刚度经敲击测试验证
- [ ] 电机座与管壁贴合、螺丝有防松
- [ ] 线束固定，无自由摆动段
- [ ] 防水等级满足作业环境

## 8. 常见错误

1. 先买桨再定轴距，桨尖太近导致涡流干扰与噪声；
2. 折叠件省刚度，飞起来 80 Hz 处一个尖峰；
3. 水箱挂在机腹一侧，重心横移，姿态长期带偏；
4. 电机线在管内自由晃动，磨破绝缘；
5. 用软减震垫解决结构共振——只是把问题挪到更低频。
