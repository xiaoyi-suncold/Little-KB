# 适航与型号审定

> 适航不是「考试」，是证明「你的设计、生产、运行三条线都可控」。
> **本文只做工程视角的流程梳理，不构成合规结论，以民航局最新文件为准。**

## 1. 中国无人机管理的三条线

| 线 | 管什么 | 主要依据 |
| --- | --- | --- |
| 运行 | 谁能飞、在哪飞、怎么飞 | 《无人驾驶航空器飞行管理暂行条例》、《民用无人驾驶航空器运行安全管理规则》 |
| 适航 | 产品本身安全不安全 | 适航审定/安全评定相关程序与指南 |
| 人员 | 操控员资质 | 执照与训练要求 |

三条线互相独立又互相引用：没有适航不代表不能飞（微型/轻型有豁免），但进入特定重量与运行场景后，适航会成为前置条件。

## 2. 三个证的概念

| 证 | 英文 | 含义 |
| --- | --- | --- |
| 型号合格证 | TC | 这个**设计**符合审定基础 |
| 生产许可证 | PC | 这个**生产线**能稳定造出符合设计的产品 |
| 适航证 | AC | 这一**架**产品可以安全运行 |

无人机的实践里，中小型产品更多走「适航安全评定」而非完整 TC 路线；大型/载人级才接近传统 TC/PC/AC 全套。

## 3. 审定的基本流程

```
申请 → 确定审定基础（适用条款） → 提交符合性计划
     → 符合性验证（MOC 0–9） → 局方审查 → 颁发证件
```

符合性方法（MOC）常见类型：

| MOC | 方法 | 例子 |
| --- | --- | --- |
| MOC 0 | 声明 | 引用标准条款 |
| MOC 1 | 设计评审 | 图纸与计算书 |
| MOC 2 | 分析 | 强度/热/电磁仿真 |
| MOC 3 | 安全评估 | FMEA、FTA |
| MOC 4 | 试验室试验 | 振动台、环境箱 |
| MOC 5 | 机上地面试验 | 系留、电磁兼容 |
| MOC 6 | 飞行试验 | 性能、操稳、失效注入 |
| MOC 7 | 航空器检查 | 目视与实测 |
| MOC 8 | 模拟器试验 | 难以实飞的场景 |
| MOC 9 | 设备鉴定 | 外购件合格证明 |

## 4. 设计保证体系（DAS）

适航审查真正看的是「你有没有能力持续保证安全」，包括：

- **构型管理**：每个零件、每版软件、每套参数都可追溯；
- **供应商控制**：外购电机、电池、飞控的质量证据链；
- **问题报告与纠正**：缺陷如何闭环；
- **持续适航**：出货后如何跟踪、召回、升级。

对研发团队的直接要求：**参数文件、固件版本、结构图纸必须版本化**——这也是本知识库强调「参数可审计」的原因。

## 5. 对设计的实际影响

| 要求 | 设计响应 |
| --- | --- |
| 可追溯 | BOM/固件/参数三件套绑定版本号 |
| 失效安全 | 失效模式分析（FMEA）+ 注入试验 |
| 环境适应 | 高低温、振动、防水试验数据 |
| 电磁兼容 | 布线、屏蔽、EMC 测试 |
| 软件质量 | 编码规范、单元测试、版本冻结 |

## 6. 中小团队的务实路径

1. 先明确产品属于哪一类、要进什么运行场景（决定是否需要适航）；
2. 把「设计保证」的最小集做起来：版本管理 + 试验记录 + 问题闭环；
3. 用第三方检测报告（振动、EMC、电池）替代部分自证；
4. 量产前补 PC 相关的产线一致性控制；
5. 持续适航从第一台交付就开始记录。

## 7. 常见误解

- 「我们有检测报告就等于适航」——不是，报告只是 MOC 证据之一；
- 「小飞机不用管」——取决于运行场景与重量分级；
- 「先卖再补证」——运行规则可能直接卡住商业运营；
- 「适航只管硬件」——软件与参数同样在审查范围内。
