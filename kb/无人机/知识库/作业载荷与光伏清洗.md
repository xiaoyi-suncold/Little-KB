# 作业载荷与光伏清洗

> 清洗机的难点不在飞，而在「带着一箱会晃的水，贴着板面稳定地走」。

## 1. 载荷构成

| 部件 | 作用 | 对飞行的影响 |
| --- | --- | --- |
| 水箱 | 储水/清洗液 | 重量随作业递减，重心随液面晃动 |
| 水泵 | 提供压力与流量 | 电流冲击、反扭、振动 |
| 管路/喷头 | 雾化与覆盖 | 水雾影响光流/测距/电机 |
| 滚刷/刷盘 | 机械擦洗 | 接触反力、额外扭矩 |
| 吸附/贴附机构 | 贴近板面 | 气动干扰、控制耦合 |

## 2. 水重与重心

1 L 水 = 1 kg。50 L 水箱满载 50 kg，相当于一台中型机自重。

**关键问题**：水量从 100% 降到 10%，起飞重量变化可达 45 kg。应对方式：

- 结构：水箱布置在重心附近，隔板抑制晃动（sloshing）；
- 软件：`MOT_HOVER_LEARN` 让悬停油门自适应，或按水量分参数组；
- 控制：垂直环要留足积分余量（`PSC_D_ACC_IMAX`），否则满载掉高、空载上窜。

## 3. 泵与喷头

```
泵功率 P = (流量 Q × 压力 p) / 效率 η
```

例：4 L/min（6.7×10⁻⁵ m³/s）、0.5 MPa、η=0.6 → P ≈ 56 W。看似不大，但启动瞬间电流可达额定 3–5 倍，会拉低母线电压。

**电气设计**：水泵走独立供电与保险，控制信号经继电器/电调，避免与飞控共地噪声；软启动或 PWM 调速减少电流冲击。

## 4. 反扭与偏航

泵与刷盘产生的反扭矩会持续作用在机体上：

- 表现：航向缓慢漂移，松杆后机头偏；
- 处置：偏航角速度环要有足够积分（`ATC_RAT_YAW_I`），而不是只靠 P；
- 若偏航持续振荡，说明 I 过大或结构柔性大，需在「抗反扭」和「不振荡」之间折中；
- 反扭随泵速变化，最好让泵速与控制解耦（定速泵）。

## 5. 水雾对传感器的影响

| 传感器 | 影响 | 处置 |
| --- | --- | --- |
| 光流 | 水雾导致纹理模糊、速度估计失效 | 不依赖光流，或加防护罩 |
| 测距（激光/超声） | 水滴散射、误测 | 加遮光罩、提高滤波 |
| 气压计 | 水汽进入导致漂移 | 密封舱 + 透气膜 |
| 电机/电调 | 进水短路 | IPX5 以上、灌封、滴水弯 |

## 6. 贴板作业的控制要点

- 高度保持用测距仪（`EK3_SRC1_POSZ` 选测距）比气压稳；
- 水平位置用 RTK 或视觉，GPS 在楼宇间多路径严重；
- 速度要低（0.3–1 m/s），否则水膜覆盖不均；
- 遇阵风时不要用位置环硬顶，优先降速/退让；
- 板面反光会影响视觉与激光，测试要在真实光照下做。

## 7. 作业参数（业务侧，不是飞控参数）

| 参数 | 典型范围 | 说明 |
| --- | --- | --- |
| 飞行高度（距板） | 2–5 m | 太低水雾反弹，太高覆盖差 |
| 作业速度 | 0.3–1.0 m/s | 与泵流量匹配 |
| 喷头压力 | 0.3–0.8 MPa | 雾化与耗水平衡 |
| 覆盖率 | 按水质与污渍定 | 需现场标定 |
| 单架次水量 | 20–50 L | 与电池续航匹配 |

## 8. 安全清单

- 水泵与飞控供电隔离，避免浪涌复位飞控；
- 水箱加液位传感器，低水位告警；
- 漏水检测（机腹传感器/视觉巡检）；
- 电机与电调防水等级满足冲洗环境；
- 作业区下方无人员，水雾会扩散；
- 电量与水量双阈值返航：先到者触发。

## 9. 与飞控参数的接口

| 需求 | 参数 |
| --- | --- |
| 泵/阀控制 | `SERVO*_FUNCTION`（辅助功能）、`RELAY*_PIN/FUNCTION` |
| 厂商定制泵逻辑 | `WATER_PUMP_AUTO`（非标准 Copter 参数） |
| 载重变化自适应 | `MOT_HOVER_LEARN`、`MOT_THST_HOVER` |
| 垂直环承载能力 | `PSC_D_ACC_IMAX`、`PSC_D_VEL_I` |
| 低水量/低电量返航 | `BATT_FS_LOW_ACT` + 业务逻辑 |
