# 点云处理与光伏巡检

> 雷达装上去只是开始，真正交付的是**带坐标的点云、缺陷清单和报告**。

## 1. 数据链

```
雷达 → ROS bag / 原始包 → 解算（FAST-LIO / LOAM / 厂商工具）→ 点云 + 轨迹 → 后处理 → 成果
```

- **解算**：有 IMU 的雷达（如 MID-360）可直接跑 FAST-LIO，输出去畸变点云与轨迹；
- **配准**：多架次点云用 ICP 或控制点配准；
- **坐标**：局部 ENU → UTM/WGS84，RTK 固定解可到厘米级。

## 2. 三件工具的分工

| 工具 | 擅长 | 典型操作 |
| --- | --- | --- |
| 大疆智图（DJI Terra） | 可见光/激光建模、正射、DSM | 导入照片/L2 数据 → 空三 → 重建 → 出图 |
| CloudCompare | 点云查看、配准、剖面、体积 | ICP 配准、去噪、裁剪、两期对比 |
| LAStools | 批量命令行处理 | `lasground` 分地面、`lasclassify` 分类、`las2dem` 出 DEM |

**流程建议**：Terra 出正射与 DSM → CloudCompare 做局部比对 → LAStools 批量出 DEM/分类。三者的坐标系要统一，否则叠不上。

## 3. 光伏巡检要什么

| 项目 | 数据源 | 判据 |
| --- | --- | --- |
| 组件定位与编号 | 可见光正射 + 点云 | 组件边界、串号 |
| 热斑/二极管故障 | 红外（双光吊舱） | 温差阈值 |
| 遮挡与积灰 | 可见光 + 清洗前后对比 | 透光率/反射率变化 |
| 支架变形/坡度 | 点云/DSM | 平面拟合残差 |
| 清洗效果 | 前后两期点云/影像 | 反射率或图像差异 |

## 4. 精度与误差来源

| 误差源 | 量级 | 控制方法 |
| --- | --- | --- |
| RTK 状态 | 固定解 cm / 浮点 dm | 检查固定解与基线 |
| 雷达外参 | 1° 姿态误差 → 10 m 处 17 cm | 控制点标定 |
| 时间同步 | 1 ms → 10 m/s 时 1 cm | PPS/PTP |
| 点云配准 | 依赖重叠度 | 增加重叠、用靶标 |
| 杆臂（GNSS 与雷达） | 直接平移 | 实测并写入 |

## 5. 一次巡检的完整流程

1. 现场踏勘：光照、遮挡、禁飞区、起降点；
2. 航线规划：高度、重叠率、速度（点云建议 ≤3 m/s）；
3. 飞行：RTK 固定解、匀速、避免急转；
4. 数据检查：点云完整、无断帧、时间戳连续；
5. 解算与配准；
6. 出成果：正射、DSM、点云、缺陷表；
7. 归档：原始数据 + 参数 + 报告，可追溯。

## 6. 常见坑

- 只拍可见光，没有热红外，热斑查不出来；
- 点云没有 RTK，绝对坐标对不上，两期无法比对；
- 外参没标，平面是斜的，量出来的坡度全错；
- 时间戳不同步，运动畸变去不掉，直线变弯；
- 用消费级软件处理大场景，内存爆掉——分块处理。
