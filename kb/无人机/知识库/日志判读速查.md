# 日志判读速查

> 日志不是「留着出事再看」，而是每次调参的对照组。

## 1. 常用消息

| 消息 | 关键字段 | 看什么 |
| --- | --- | --- |
| `ATT` | `Roll`/`RollDes`、`Pitch`、`Yaw` | 实际 vs 期望，超调与滞后 |
| `RATE` | `R`/`RDes`、`P`、`Y` | 内环跟随、振荡频率 |
| `RCOU` | `C1..C8` | 电机输出是否饱和/贴顶 |
| `VIBE` | `VibeX/Y/Z`、`Clip0..2` | 振动与削顶 |
| `IMU` | `AccX/Y/Z`、`GyrX/Y/Z` | 原始波形、削顶 |
| `CTUN` | `ThO`、`ThH`、`DAlt`、`Alt` | 悬停油门、高度响应 |
| `XKF1` | `PN/PE/PD`、`VN/VE/VD` | 位置/速度估计 |
| `XKF4` | `SV`、`SP`、`SH`、`SM` | 各状态方差（健康度） |
| `BAT` | `Volt`、`Curr`、`CurrTot` | 电压曲线、压降、耗电 |
| `MAG` | `MagX/Y/Z`、`OfsX` | 磁干扰 |
| `GPS` | `NSats`、`HDop`、`Status` | 定位质量 |
| `PM` | `NLon`、`Mem`、`Load` | 飞控负载、丢帧 |
| `MODE` | `Mode`、`Rsn` | 模式切换与原因 |

## 2. 判读顺序

1. **先看 `MODE` 与事件**：什么时候切模式、为什么（`Rsn`）；
2. **看 `VIBE`**：振动不过关，后面都没意义；
3. **看 `ATT` 与 `RATE`**：外环跟不跟、内环振不振；
4. **看 `RCOU`**：是否饱和——饱和说明动力/限幅不足，不是增益问题；
5. **看 `XKF4`**：估计是否健康；
6. **看 `BAT`**：电压塌陷会连带姿态异常。

## 3. 几个特征波形

| 波形特征 | 含义 |
| --- | --- |
| `RATE` 等幅正弦、频率固定 | 典型振荡，降对应轴 P 或查 D/滤波 |
| `RCOU` 某一路长期贴 100% | 该轴动力不足或重心偏，增益再加也没用 |
| `ATT` 跟随有 0.2–0.5 s 滞后 | 角度环 P 偏低或 `ATC_INPUT_TC` 过大 |
| `VIBE` 与油门强相关 | 桨/电机问题，不是结构 |
| `XKF4.SV` 周期抬升 | GPS/罗盘不稳定，融合在犹豫 |
| `BAT.Volt` 锯齿 | 大电流瞬间压降，检查线径/连接器/内阻 |

## 4. 调参对照法

每次改参数前导出一份日志，标注：

```
日期/机型/改动项（旧值→新值）/环境（风、温度、载重）/动作（3 秒满杆、悬停 60 秒）
```

同一动作、同一载重、同一时间段对比，才有可比性。

## 5. 采样与带宽

- 默认日志 10 Hz 足够看姿态与位置；
- 分析振动要开 `INS_LOG_BAT_MASK`（批量 IMU，高采样率）；
- 日志速率过高会掉帧，看 `PM.NLon`（长循环次数）判断是否过载。
