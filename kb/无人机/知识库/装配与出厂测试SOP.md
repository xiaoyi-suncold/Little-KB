# 装配与出厂测试 SOP（工业无人机）

> 装配质量决定振动的下限，出厂测试决定交付后的返修率。

## 1. 来料与结构装配

| 项 | 要求 |
| --- | --- |
| 碳管/碳板 | 无分层、无裂纹，孔位加沉头 |
| 螺丝 | 按规格用扭矩扳手（M3 约 1.2 N·m），关键处加螺纹胶 |
| 电机座 | 与管壁贴合 ≥80%，四颗螺丝对角紧固 |
| 折叠件 | 锁紧后无旷量，插拔 50 次复检 |
| 起落架 | 有缓冲，触地不传递冲击到机臂 |

## 2. 布线（最容易出事的一环）

1. **功率与信号分离**：电源线走一侧，信号线走另一侧，交叉处垂直通过；
2. **双绞**：CAN、RS485、PWM 长线双绞；
3. **屏蔽**：罗盘线、图传线用屏蔽线，屏蔽层单端接地；
4. **接地**：单点接地，避免地环路；
5. **滴水弯**：所有接头朝下或做滴水弯，清洗机尤其；
6. **固定**：扎带间距 ≤10 cm，线束无自由摆动段；
7. **标签**：两端贴编号，维修可追溯。

## 3. 焊接与连接器

- 线径按 4–6 A/mm² 选，长线降一档；
- 大电流焊点饱满、无虚焊，焊后热缩管包覆；
- XT90/AS150 定期检查氧化，插拔次数有限；
- 电池主回路加保险或断路器；
- 焊后做**拉力测试**（轻拉不脱）与导通测试。

## 4. 减震

| 部位 | 做法 | 注意 |
| --- | --- | --- |
| 飞控 | 减震球/减震板 | 太软会引入低频摆动 |
| IMU | 与机架隔离 | 避免与电池硬连接 |
| 雷达 | 减震支架 | 不能太软，否则点云抖 |
| 相机 | 云台或软连接 | 避免果冻效应 |

## 5. 重心与称重

- 空机、满载分别称重；
- 吊点法找重心，前后左右偏差 ≤5% 轴距；
- 水箱/载荷布置在重心附近，隔板抑制晃动；
- 记录到出厂档案（影响后续配平与参数）。

## 6. 出厂测试（按顺序做，每步留记录）

| 步骤 | 内容 | 通过标准 |
| --- | --- | --- |
| 1 | 外观与紧固 | 无松动、无划伤、标签齐全 |
| 2 | 通电自检 | 无异常告警、电压正常 |
| 3 | 电机顺序与转向 | 与混控表一致，反转即改相线 |
| 4 | 电机最小起转 | 四/六路同步起转，无异响 |
| 5 | 拉力测试（系留） | 达到设计值 ±5% |
| 6 | 振动基线 | 地面旋转 `VIBE` 在阈值内 |
| 7 | 罗盘一致性 | 电机转动时航向变化 < 阈值 |
| 8 | GPS/RTK | 固定解、卫星数、HDOP 合格 |
| 9 | 失效保护触发 | 拔遥控、关地面站、越界各测一次 |
| 10 | 悬停 60 s | 高度、振动、电流、温度正常 |
| 11 | 日志与参数导出 | 归档，可追溯 |

## 7. 包装与运输

- 电池单独包装、电量 30–50%；
- 机臂折叠处加保护，桨叶拆下单独放；
- 运输箱防震，标注"勿倒置"；
- 随箱附：出厂测试报告、参数文件、备件清单。

## 8. 追溯

每台机一个档案：序列号、BOM 批次、装配人、测试记录、参数版本、维修历史。适航或大客户交付时，这套档案就是证据链。
